## MVP 阶段规划

### MVP 1.0（4-8周可落地试点）✅ 已完成

**目标**：验证"当天补懂"闭环，家长能"看完就会做动作"

| 功能 | 状态 | 说明 |
|------|:----:|------|
| 纯语音时间轴 | ✅ | 已实现，支持自动分段 |
| 课桌按键 | ⚠️ | 软件实现，需硬件方案 |
| 断点回放 | ✅ | 证据链输出已优化 |
| 学生问答 | ✅ | 支持卡点类型选择 |
| 家长报告 | ✅ | 概览+时间线+播放器+AI总结 |
| 行动清单 | ✅ | 3步补懂路径已优化 |
| **数据分析** | ✅ | 轻量级无感知采集 |

**过线标准**：
- 家长行动清单转化率 > 60%
- 学校/老师愿意持续让你录（留存/续用）
