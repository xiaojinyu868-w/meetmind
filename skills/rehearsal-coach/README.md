# 试讲教练（rehearsal-coach）

一个符合 Agent Skills 标准（SKILL.md 清单格式）的技能包。任意智能体加载本技能后获得"试讲排练教练"能力：扮演尖锐但善意的听众，帮用户在组会汇报、毕业答辩、求职面试、竞赛路演前把问题暴露在练习室里，而不是暴露在场上。

## 功能简介

- **听试讲并追问**：引用用户原话，挑出台下听众真实会问的 2-3 个问题
- **诊断表达结构**：按六个维度（主线 / 跳步 / 术语 / 证据链 / 时间 / 听众适配）指出问题
- **给可操作改法**："把结论挪到开头先抛出来"这种下场就能用的改法，不说空话
- **按用户思路出讲稿**：保留用户主线、例子与表达习惯，修错补漏，口语短句，标注时间分配
- **生成 Word 讲稿**：`scripts/make_docx.py` 把讲稿文本转成可下载的 .docx
- **时长估算**：`scripts/estimate_duration.py` 按中文语速估算总时长与逐段时长
- **预测台下提问**：按犀利度排序的 5 个问题 + 回答方向（不给逐字稿）

## 运行环境

- 智能体本体：任意支持 Agent Skills（SKILL.md）标准的 Agent 运行时
- 附带脚本：**Python ≥ 3.8，纯标准库，零第三方依赖**（无需 pip install）

## 目录结构

```
rehearsal-coach/
├── SKILL.md                        # 技能清单：角色、工作流、铁律、边界
├── README.md                       # 本文件
├── scripts/
│   ├── make_docx.py                # 讲稿文本 → Word .docx（zipfile 手写最小 docx）
│   └── estimate_duration.py        # 讲稿字数与时长估算（240 字/分钟 + 缓冲）
└── references/
    ├── question-patterns.md        # 分场景追问角度模式库（组会/答辩/面试/路演）
    └── rubric.md                   # 试讲诊断维度表
```

## 脚本用法示例

```bash
# 生成 Word 讲稿（首段自动加粗标题 + 生成时间，A4 页面）
python3 scripts/make_docx.py 讲稿.txt 讲稿.docx --title "组会试讲"

# 估算讲稿时长（文件输入）
python3 scripts/estimate_duration.py 讲稿.txt

# 估算讲稿时长（stdin 输入）
cat 讲稿.txt | python3 scripts/estimate_duration.py
```

输出示例：

```
=== 讲稿时长估算（语速 240 字/分钟，缓冲系数 1.15）===
总字数：1450 字
预计总时长：约 6.9 分钟
--- 逐段时长建议（共 4 段）---
  「开场，约 30 秒」：110 字，约 32 秒
  ...
```

## 限制说明

- 两个脚本均**不联网**，不发起任何网络请求
- 脚本**只读取用户显式指定的输入文件、只写入用户显式指定的输出路径**，不读写技能包目录以外的任何文件（`estimate_duration.py` 从 stdin 读取时完全不碰文件系统）
- `make_docx.py` 生成的是最小合法 docx（标题 + 按行段落 + A4 页面），不含样式表、目录、图片等高级排版；如需复杂排版请用 Word/WPS 打开后二次加工
- 时长估算按 240 字/分钟的通用中文试讲语速，实际语速因人而异，结果仅供参考
- 技能本体（追问、诊断、讲稿撰写）由加载它的智能体完成，效果取决于底层模型能力
