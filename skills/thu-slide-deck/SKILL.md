# 清华讲演 PPT 生成（THU Slide Deck）

> 为讲解而设计，不是为展示内容而设计：slide 给听众看，notes 给讲者看。
> v5：主交付改为**单文件 HTML 讲演 deck**（scripts/make_html.py）——瑞士国际主义
> 视觉（直角 / 无阴影 / 无渐变 / 1px 发丝线，主题固定清华紫），所有 CSS/JS 内联，
> 零 CDN 零网络，教室离线浏览器直接放映；新增数据页 / 对比页两种页型与
> 演讲者模式（按 P 进深色控制台：口播稿 + 意图 + 计时 + 观众屏同步翻页）。
> .pptx 降为可选导出（scripts/make_pptx.py）。
> v3 起：讲演骨架为 AST（Audience State Transition，观众状态转移）形态——
> 与用户确认的不是普通大纲，而是一条"观众从哪到哪"的状态转移弧；
> 生成后必须过 `scripts/check_deck.py` 体检再交付。

## 触发条件

- 用户要准备组会汇报、毕业答辩、竞赛路演、课程展示等口头汇报的幻灯片
- 用户发来一份讲稿、提纲或零散要点，希望变成 PPT
- 用户明确要求"清华风格""组会 PPT""答辩 PPT"

## 工作流（先讲后做）

1. **确认场合**：问清场合（组会 / 答辩 / 路演 / 课程展示）、时长、听众是谁。时长写进 `%duration`，按 10/20/30 法则估算页数上限（详见 `references/design-guide.md`）。
2. **先产 AST 讲演骨架，不做 PPT**：把汇报拆成一条**观众状态转移弧**，每页给四样东西——
   - **论断句标题**：一句完整的话，是本页结论（"多跳问答准确率从 58% 提升到 78.5%"），不是栏目名（"实验结果"）
   - **意图（`~`）**：本页的观众状态转移——观众离开这页时应该相信/感受到什么（"观众从怀疑方法转到承认提升真实"）
   - **视觉锚点**：1-3 个关键词或数字（幻灯片上只放这些）
   - **口播要点**：这页嘴上要讲什么（写进备注）
   把骨架发给用户确认的是**状态转移弧**：逐页读意图，看观众是否被一步一步带到结论。**用户没确认前不要生成文件。**
3. **翻译成 DSL**：骨架确认后写成 slides.txt（规则见下）。标题一律用论断句——用户给的"实验结果""研究方法"这类栏目名，由你翻译成论断句；每页补一行 `~ ` 意图。
4. **生成 HTML deck**：`python3 scripts/make_html.py slides.txt 输出.html`。单文件输出（CSS/JS 全内联，零 CDN 零构建），浏览器直接打开即可放映。脚本自检 data-layout 白名单、data-slide-id 唯一性、SPEAKER_NOTES 与页数一致、HTML 标签配平，失败非零退出。
5. **讲演体检（必须）**：`python3 scripts/check_deck.py slides.txt`，把体检报告原样给用户看。有 ERROR 先修再重新生成；有 WARN 逐条改或向用户说明不改的理由。**体检没过不要交付。**
6. **交付并提醒**：① 放映直接双击 HTML，按 `P` 进演讲者模式看口播稿和计时，观众屏会自动弹出；② 字越少越好、细节用嘴讲；③ 全系统字体无 webfont，离线可放映，但上场前仍要用放映机器预演。
7. **可选导出 .pptx**：用户明确需要 PowerPoint/WPS 二次加工时，再跑 `python3 scripts/make_pptx.py slides.txt 输出.pptx`（含讲者备注口播稿，放映时开演示者视图）。

## slides.txt DSL 规则

纯文本，逐行解析：

```
%title 知识图谱让多跳问答更可靠     ← 封面标题（% 元信息构成封面页）
%subtitle 2025-2026 秋季学期组会汇报
%author 张三 · 某某实验室
%date 2026-08
%duration 10                       ← 汇报时长（分钟），供体检做节奏配比 + 演讲者模式计时预算

# 多跳问答准确率从 58% 提升到 78.5%   ← "# " 开一页，标题写论断句
~ 观众从怀疑方法转到承认提升真实      ← "~ " 意图声明（观众状态转移，不渲染）
- 测试集：CCKS2022 KGQA 评测        ← "- " 一级要点（紫色 8×8 方块 marker）
  - 2-hop 以上提升 +20.5%          ← 行首两个空格 + "- " 是二级要点（灰 en-dash）
>> 先抛结果，然后解释基线为什么公平：  ← ">> " 讲者备注（口播稿，可多行）
>> 同样的大模型、同样的语料，唯一变量是检索方式。

# 章节：实验结果                   ← 标题以「章节：」开头 → 章节过渡页
# 强调：推理路径是可解释的           ← 标题以「强调：」开头 → 强调页（整页紫底超大字单句）
# 数据：多跳问答准确率提升到 78.5%    ← 标题以「数据：」开头 → KPI 数据页（v5 新增）
- 78.5% | 多跳问答准确率 | 较基线 +20.5pt   ← 数据页要点行：数字 | 标签 | 注释（注释可省）
# 对比：从匹配文本到走路径           ← 标题以「对比：」开头 → 左右对比页（v5 新增）
- 检索到的是碎文本片段 | 检索出的是完整推理路径  ← 对比页要点行：左侧文本 | 右侧文本
# 谢谢聆听                         ← 谢谢聆听/谢谢/恳请批评指正 → 结尾页
- 知识图谱让多跳问答可追溯           ← 结尾页带要点 → 右半白底 takeaway 列表
```

- `%title / %subtitle / %author / %date` 须写在第一个 `# ` 之前；全部省略则不生成封面。`%duration` 同样写在这里，单位分钟：供体检做节奏配比，并在演讲者模式里按页数平摊出每页分钟预算。
- `~ ` 意图行归属当前页，一句观众状态转移（"观众离开这页时应该相信：…"）；**不渲染进幻灯片**，只被 check_deck.py 检查、并进入演讲者控制台的 intent 栏。
- `>> ` 备注行归属当前页，可写多行，每行一段；只出现在演讲者控制台 / pptx 演示者视图，**绝不出现在观众屏**。
- 二级缩进严格是**两个半角空格**。空行、`//` 开头的行被忽略。
- 特殊字符（`&` `<` `>` `"`）**原样写**，脚本统一转义。
- 页型触发只认标题文本：「章节：」→ 章节页；「强调：」→ 强调页；「数据：」→ 数据页；「对比：」→ 对比页；整标题等于「谢谢聆听 / 谢谢 / 恳请批评指正」→ 结尾页；其余 → 内容页。
- **数据页**：要点行格式 `- 数字 | 标签 | 注释`，2-4 个 stat 列；列顶 2px 紫线，焦点列（默认第一列，或注释含"焦点"二字的列）紫底反白。
- **对比页**：要点行格式 `- 左侧文本 | 右侧文本`，逐行成对，中缝 1px 竖线；左半 opacity .62（旧/现状），右半全浓度（新/方案）。
- **结尾页**：不带要点 → 整页紫底大字；带 `- ` 要点 → 左半紫底大字「谢谢聆听」，右半白底 takeaway 列表，第 3 条紫色（与封面色彩闭环）。
- 标题中可用 `*强调字*` 标记斜体强调（紫底页用 italic 而非换色）。
- 单页要点超过 7 条，脚本在 stderr 提示"建议拆分"——不报错，但你应该回头拆页；check_deck.py 会在 >6 条时 WARN、>9 条时 ERROR。

## HTML deck 放映操作

- **翻页**：←/→（或 PageUp/PageDown/空格）、Home/End 跳首尾、滚轮（600ms 防抖）、触屏滑动、底部 6×6px 直角导航点（active 紫、宽 18px）。
- **跳页**：URL hash `#3` 直达第 3 页（截图测试/分享定位用）。
- **ESC 总览**：网格缩略图，点击跳页，再按 ESC 关闭。
- **P 演讲者模式**：当前窗口变深色控制台——左侧当前页 16:9 实时预览，右侧本页口播稿 + 意图 + 下一页标题预告，底部计时器（开始/继续/重置 + 已进行/剩余，按 `%duration` 预算）与页码。同时自动 `window.open` 同文件 `?audience=1&session=<ts>` 弹出**干净观众屏**（无导航点、无快捷键提示），BroadcastChannel（`thu-deck:<session>`）+ postMessage 双通道同步翻页，控制台显示「观众屏已同步 / 未连接」；弹窗被拦截会提示，允许后重新按 P。退出（再按 P 或 ESC）观众屏显示「演示已结束」。
- **B 静态模式**：关闭入场动效（低功耗/老旧机器），localStorage 记忆；`prefers-reduced-motion` 自动尊重。

## 讲演体检（check_deck.py）

生成后必跑：`python3 scripts/check_deck.py slides.txt`。确定性检查六类问题，每条给出页号 + 问题 + 改法：

- **标题论断**：栏目名式标题（以 背景/方法/实验/结果 等栏目词结尾或 ≤6 字）→ 改成完整论断句（「数据：」「对比：」前缀不计入检查）
- **要点密度**：一级要点 >6 条 WARN 拆页、>9 条 ERROR；单条 >40 字 WARN（要点是关键词不是句子）
- **口播稿缺失**：内容页（含数据/对比页）没有 `>> ` 备注 → 演讲者控制台会是空的
- **意图缺失**：内容页（含数据/对比页）没有 `~ ` 声明 → 这页要把观众从哪带到哪？
- **节奏配比**：声明 `%duration` 时，内容页数 > 分钟数 → 讲不完；< 分钟数 ×0.4 → 撑不满
- **结构建议**：内容页 >10 且无章节页 → 加章节过渡页

末尾总评给出"能否上台"判断；有 ERROR 时退出码为 1，可直接接 CI 或钩子。

## 设计规范

方法论（AST 状态转移、assertion-evidence、10/20/30、注意力曲线、强调页使用时机、组会 vs 答辩 vs 路演差异）与 HTML 视觉系统（token / 字号字重双阶梯 / 瑞士纪律 / 演讲者模式契约）见 `references/design-guide.md`。出骨架阶段就要按它来，不要等生成完再返工。

模板固定（不可调参）：主题固定清华紫 `#660874`，纸面微紫暖白 `#FBFAFC`、墨色近黑 `#16101C`；七种页型 COVER / SECTION / STATEMENT / CONTENT / DATA / COMPARE / CLOSING；全系统字体栈（离线可放映）；装饰只允许 1px 发丝线与小色块。pptx 导出保留明暗三明治封面与"清华大学"页脚页码。

## 边界

- **纯文字排版**：不生成图片、图表、表格。用户需要数据图时：HTML deck 让他在别的窗口放图，或用 `# 数据：` 页承载关键数字；pptx 导出后可在 PowerPoint/WPS 里插图。
- **不含官方素材**：脚本不内置校徽、校名标准字等受 VI 规范约束的素材；用户需要时提示其按学校 VI 规范自行添加。
- **论断句不能编**：标题里的数字和结论以用户提供的材料为准，编不准就留空让用户填，不硬编一个看似专业的论断。
