# MeetMind 学习上下文产品模型

> 版本：v1.3 · 2026-07-18

## 1. 产品判断

“我的上下文”不是记忆数据库，也不是给用户维护字段的工作台。对学生真正有价值的是三件事：

1. 看见 MeetMind 如何理解自己，并能纠正；
2. 看见哪些课堂正在组成一门课程，并能控制边界；
3. 随时回到客观发生过的学习现场。

因此页面采用“总览 → 具体内容”的浅层结构，不新增“个人 / 课堂 / 课表 / 考试”多层 Tab。总览只展开最需要用户确认的“对我的理解”，以两条安静入口进入“课程与考试”或“最近学习现场”；避免三类内容一次性纵向铺满，也不把用户变成数据库管理员：

| 层 | 内容 | 谁产生 | 用户控制 |
|---|---|---|---|
| 对我的理解 | 方式、进展、困难、关注点 | 用户陈述 + 模型从真实表现中整理 | 纠正、暂停、忘记 |
| 我的课程 | 课堂 session、课程边界、重复上课时段 | 客观数据 + 智能归组 | 改名与标签、移出/放回错归课堂、暂停/恢复参考 |
| 最近学习现场 | 课堂、材料、对话、练习事件 | 系统客观记录 | 回到原现场，不被模型改写 |

“暂停参考”不等于删除。学生可以不让某门课进入 AI 的跨课背景，但录音、转录、笔记和时间线仍完整保留。

## 2. 课程如何自然长出来

系统不要求学生先维护课表。归组优先级为：

1. 用户或导入来源给出的明确课程名；
2. 去掉“第 N 讲 / 日期”后仍稳定重复的课堂标题；
3. 多周重复的星期与时间段，只显示为“暂归建议”；
4. 没有可靠线索时保持单节课堂，宁可不归组也不误合并。

URL、裸日期和裸时间永远不能直接成为课程标题；没有可信名称时显示“待命名课程”，并保留来源类型与上课时段作为辅助线索。用户可以改名、补充少量标签，也可以在不改名时直接确认课程边界。未来接入课表时，课表只是一种低成本证据源，不成为使用产品的前置任务。

## 3. 学习对象层级

数据关系是嵌套的，用户价值是逐层出现的：

```
原件 / 片段 → 一节课 → 课程单元 → 一门考试 → 长期个人上下文
```

- 一节课：回答“刚才讲了什么、哪里没懂、能不能复述出来”；
- 课程单元：回答“几节课如何连接、概念怎么区分、能否综合运用”；
- 一门考试：回答“考什么、我缺什么、有限时间和纸面空间如何分配”。

模型可以建议归组，学生拥有最终边界权：移动一节课、合并/拆分单元、排除无关材料。

## 4. 各层高价值交付

| 层 | 默认交付 | 按需应用 |
|---|---|---|
| 单课 | 课堂脉络、用户标记、一个低成本理解检验 | 闪卡、测验、思维导图、信息图、音频复述 |
| 单元 | 主线、跨课连接、相似概念对比、单元薄弱点 | 单元测验、单元闪卡、单元速查表 |
| 考试 | 范围覆盖、薄弱项、时间计划、模拟结果 | 考试速查表、模拟卷、错题复练 |

考试速查表不属于单课。单节课可以产生“课堂提要”，但不能冒充覆盖完整范围的考试工具。

## 5. 考试速查表的真实场景

速查表首先是物理打印品，其次才是屏幕内容。生成前需要知道或采用可修改默认值：

- 考试用途：允许带入考场 / 仅考前复习；
- 纸张：A4 或 Letter；
- 页数：1–6 页；
- 方向：横向 / 纵向；
- 单双面与黑白 / 彩色；
- 考试范围、课程单元和截止日期。

内容证据优先级：

1. 课堂转录与老师明确强调；
2. 课件、教材、学生笔记；
3. 考试大纲、允许范围、历年题；
4. 外部资料只能补背景，必须显式标注，不能伪装成老师讲过。

只有大纲或历年题能支持“高频 / 常考”判断。没有这类证据时，产品只写“核心内容”，不写“必考”。

当前采用“直接在纸面预览上轻编辑”的 To C 形态，避免先进入一套文档工作台。学生可改术语/解释/公式、删条目和整区收起；屏幕页界与打印页界共用同一分页模型。若真实用户出现长时间重排需求，再升级为桌面双栏编辑器，移动端仍只承担范围确认、删减与轻编辑。

## 6. 当前实现边界

- 已实现：课程上下文从真实课堂自动归组，URL / 裸日期 / 裸时间不会再冒充课程名；支持重复时段建议、改名与标签、错归课堂移出/放回、暂停/恢复参考；
- 已实现：应用目录和前后端 readiness / execute 双重层级门禁，单课不再出现考试速查表；
- 已实现：考试范围采用课程 + 课次两层多选，可跨课程精确勾选至少两节课堂；桌面使用课程侧栏 + 课次画布，手机使用横向课程选择带并只展开已选课程的课次，避免自上而下堆成长表单；构造带原课程名与课次来源映射的 `ContextPack`，默认仅预选最近课程的四节，不静默吞掉整学期；
- 已实现：从复习页的考试速查表入口进入时直接打开范围选择；返回恢复原复习现场，不把用户丢进全局问答；
- 已实现：课程内的轻量考试对象；平时不展示表单，学生主动标记后只需确认考试名、日期、开闭卷与可选大纲。考试对象直接复用课程课堂，范围仍由学生最终勾选；
- 已实现：考试对象将多课 ContextPack 升级为 exam tier，把考试名、日期、方式和大纲作为独立证据传给速查表，不把模型推断冒充老师要求；结束准备后保留历史对象但不再占据课程首屏；
- 已实现：A4/Letter、横纵向、1–3 张、单双面、彩色/黑白、字号、考前/开卷预设；条目可改、可删、区块可收起，屏幕与打印使用同一真实分页结果；
- 已实现：每条内容重新落回课堂 / 大纲 / 真题证据；课堂引用显示“课次 + 课内时间”，大纲与真题不伪造课堂时间；
- 待完成：将单节课堂直接移动到另一门既有课程、课程合并/拆分、真题/课件/教材/学生笔记并入 ContextPack、跨单元范围管理与真实打印机矩阵回归。
