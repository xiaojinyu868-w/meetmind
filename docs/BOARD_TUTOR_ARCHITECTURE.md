# 板书家教架构设计：站在研究肩膀上的 AI 一对一

> 本文是「板书精讲」从"黑板播放器"走向"一对一家教"的架构蓝图。
> 每条设计决策标注三个东西：**依据**（论文/产品实践，带证据等级）、**用什么模型**、**踩哪个开源项目**。
> 证据等级：【强】= RCT/元分析/被反复复现；【中】= 大样本产品实测数据；【弱】= 机制推理/单一来源/有争议。
> 调研底稿：经典学习科学（Bloom/VanLehn/Chi/Sweller/Shute/Graesser…）、LLM 家教前沿 2023–2026（Tutor CoPilot/LearnLM/Khanmigo/MathDial/Bastani…）、名师与产品实践（bansho/变式教学/张景中/洋葱/Duolingo/Desmos/3Blue1Brown…）。

## 0. 设计宪法（优先级高于一切研究结论）

1. **即刻 AHA 优先**。前 60 秒让用户感到"它理我了、它讲我的题、它看见我写的字了"。研究是工具箱，不是教条；凡与即刻价值冲突的教学法（如死守苏格拉底不给答案）一律降级为后续选项。
2. **参与度是生死线**。NBER 两年 RCT（2026-08，田纳西 18 所中学）：Khanmigo 进校两年效果 ≈ 不带 AI 的练习，瓶颈是学生只在 17% 的出错时刻求助。【强】学习科学只在把人留住之后才有意义。
3. **两层分离**：即刻价值层现在做；长期效果层（知识追踪、变式、间隔复习）留好接口、逐步融入，不以打扰体验的方式上台。
4. **The Bitter Lesson 修正（Sutton）**：本文引用的相当部分研究出自模型能力弱的时代（GPT-3.5/4 早期），其"模型不可靠所以要手工编码护栏/话术/状态机"的结论会随模型变强而过期。因此架构原则是：**相信大模型与未来大模型的能力**——不把教学策略手工编码成脆弱的规则系统（五级提示阶梯写死、固定话术库、tutor move 分类器硬门控这类 2023 时代补丁一律不做）；把工程投入集中在模型变强后依然增值的东西上：**数据**（步级作答事件、学生历史）、**上下文**（把正确的信息喂给模型）、**交互结构**（步级、可打断、可插手的黑板形态）与**评测**。凡是"模型 + 好上下文"能涌现出来的行为（引导、纠错、鼓励、因人调整讲法），都让模型涌现，我们只提供上下文和结构，不替它写脚本。历史结论中被此条降级的，在各节以 ⚡ 标注。
5. **少结构、多智能（2026-08-18 定稿，对齐 `项目开发文档/提示词设计哲学.md`）**：prompt 只写**输出契约 + 品味宪法**，删掉一切微管理（页结构配方、密度数字、字数上限、节奏数值表）——实测硬规则挡不住的问题（节奏不像真人）恰恰需要模型智能去解决；主模型向最强思考模型收敛（Kimi K3，开通后 `BOARD_PHOTO_ONESHOT_MODEL` / `BOARD_EXPLAINER_MODEL` 一键切换）。保留的"结构"只有机械防线：sanitize、引用逐字校验、播放器对时——它们防的是模型偶发错误，不是替模型做判断。

## 1. 核心命题：家教到底为什么有效

- 家教的魔力不在"像真人"，在**步级交互**。VanLehn 2011：真人辅导 ~0.79σ，step-based ITS ~0.76σ，一次性给完整讲解只有 ~0.31σ；真人 vs 逐步系统无显著差异。【强】2-sigma 是营销神话（不可复现，Slavin 1987 / Walberg 元分析 ~0.40），真实天花板 ~0.8σ，AI 完全够得着——**前提是把每道题拆成可交互的步骤**。
- 学生产出才是学习增益的主预测因子，不是老师讲得多精彩（Chi et al. 2001；Lepper & Woolverton 2002 对专家真人家教的录像研究）。【强】
- 我们的形态有证据背书：**dynamic drawing principle**（Fiorella & Mayer 2016–2020）——看讲师边讲边画优于看预完成的图；逐笔渲染是 signaling（注意引导）+ temporal contiguity（音画同步）机制，不是视觉糖。【中-强】

结论：产品北极星 = **把每一次讲解都变成步级的、学生可插手的双向过程**，并用 Khan 的度量：**next-item correctness**（被辅导后下一题独立做对）【中：Khan 2026 工程复盘，1500 万会话 20 组 A/B】。护栏指标：泄题率、数学错误率（Bastani PNAS 2025：裸 GPT 练习 +48% 但撤掉 AI 考试 −17%【强】）。

## 2. 架构分层

```
┌─────────────────────────────────────────────────┐
│ L4 留存层：微家教 streak / 进步可视化（后续）      │
├─────────────────────────────────────────────────┤
│ L3 上下文层：学生模型（结构化历史 → 注入上下文）   │
├─────────────────────────────────────────────────┤
│ L2 交互层（AHA 层）：拍题开讲 / 语音插话 /        │
│    点板追问 / 板演批改示范 / checkpoint           │
├─────────────────────────────────────────────────┤
│ L1 讲解引擎：tutor move 两段式 + BoardScript +    │
│    bansho 版面规划 + 讲解词写作宪法               │
├─────────────────────────────────────────────────┤
│ L0 确定性层：数学验算通道（LLM 只做表达不做判断）  │
└─────────────────────────────────────────────────┘
```

### L0 确定性层：数学判断必须有非 LLM 兜底

- **依据**：Khanmigo 工程复盘——独立 math agent 实时验算，"只验学生已写的步骤、不预解剩余步骤"，延迟 −400ms、泄题 −50%【中】；洋葱十年复盘——基于标准答案生成解析 + 系统自我核查【中】；Khanmigo 实测 LLM 算术错误真实存在【中】；VLM 会"过度纠正"学生手写（把错的认成对的，arXiv:2604.22774 专门研究）【中】。
- **⚡ Bitter Lesson 校准**：要保留的不是"独立审查 agent"这个形态，而是"判定锚定在计算与事实上"这个原则——符号计算/数值代入本身就是 Sutton 意义上" leverages computation "的通用方法，模型再强也不会让 2+2=5 变得可接受；但实现上不手写校验规则，让强模型自己调用工具验算（model + tools，而不是 checker pipeline）。VLM 过度纠正、LLM 算术错误都属于弱模型时代问题，预期随模型代际消失——届时这一层自然瘦身，不要为它建永久建筑。
- **设计**：BoardScript 生成后、上板前过一道独立验算（符号计算/数值代入，可用 LLM+工具链，但判定不交给讲解模型自己）；VLM 批改学生作业时用"对照验算结果"而非"自由发挥判对错"。
- **模型**：DeepSeek V4 Flash（三档思考：快答 Non-Think / 深讲 Think High）。

### L1 讲解引擎：两段式生成

- **依据**：Tutor CoPilot（Stanford，预注册 RCT，900 tutor/1800 学生，过关率 +4~14 p.p.，$20/tutor/年）【强】——先选 tutor move（提供例题/小纠正/出相似题/简化问题/鼓励…）再生成话术，比裸生成可靠；MathDial（EMNLP 2023）——GPT 是"好解题者、差家教"，倾向过早泄题，需 move 分类约束【强】。
- **⚡ Bitter Lesson 校准**：MathDial 的"泄题、不像家教"是 GPT-3.5/4 时代结论；tutor move 分类器硬门控、固定话术库这类补丁**不做**。保留的是更深层、不过期的两条：①"先规划教学意图再生成"作为提示结构（一段式强模型同样可以先想后讲，不为它单独训分类器）；②讲解词写作宪法（下文）作为**品味上下文**喂给模型——品味不随模型变强而过期，反而是模型变强后唯一稀缺的输入。不微调、不训 RoBERTa 分类器，用强模型 + 好上下文涌现教学行为。
- **设计**：BoardScript 生成管线改为两段——①规划器输出 move 序列 + bansho 版面计划；②生成器按 move 逐段写讲解词与板书动作。move 分类器同时用于线上监控（Focus/Probing/Telling/Generic 比例）。
- **bansho-keikaku（板书计划）**：日本授业研究传统【中：Stigler & Hiebert TIMSS 录像研究；Emerling 2015 实地研究】——备课先分区（题目区/学生思路区/演算区/结论框），板书从左到右形成可回溯的故事线，**关键步骤不擦**、可回指，学生解法占固定"荣誉区"。一节课结束的整板截图 = 最好的复习材料。这直接改造我们的翻页清屏逻辑。
- **讲解词写作宪法**（写进 prompt 模板）：
  - 先制造"头疼"再给"阿司匹林"——新知识点先用旧工具会卡的题制造 10 秒认知冲突，不编造假现实应用（Dan Meyer【中：教师圈最有影响力博主+Desmos 首席学术官】）；
  - 直觉先于形式、"satisfying"先于"beautiful"——追求"你看，这一步恰好卡进去了"的爽感（3Blue1Brown × Strogatz 对谈【中】）；
  - 检验标准：学生看完觉得"我自己也能推出来"，而不是"老师好厉害"（Sanderson, Lex #118【中】）；
  - 敢写硬推导，不抽掉数学本身（李永乐【中】）；
  - 边说边写、思维外化（"我看到 x² 系数是 2，所以我先试配方……"）——认知学徒制 modeling（Collins et al. 1989【强】）。

### L2 交互层（AHA 层，当前主战场）

按"60 秒让人觉得厉害"排序，全部有研究/产品背书：

1. **拍题开讲**——拍自己的作业题 → 解析 → 现场生成 BoardScript → 老师讲"你的这道题"。学生的题本身就是 Meyer 说的"头疼"，不用制造。整页结构化用 qwen3-vl-plus（QwenVL Markdown/HTML 自带版面元素位置【已核实】），质量通道可升级 Qwen3.7-Plus / Doubao Seed 2.0 Pro。冷启动铁律：context 不承担第一天价值，已有数据（作业照片）一次导入即产生当下价值。
2. **语音插话**——播放中随时说话，老师停笔、回答、从断点继续。方向有 Generative Lecture（Jo et al. 2025，把讲座视频变成可打断双向形态）【弱-中】参照；实测痛点：语音是第一交互、打字劝退低龄（Synthesis vs Khanmigo 九个月实测【中】），且必须允许"说错了改手写/点按"的降级路径。模型：Qwen3.5-Omni（帧级流式）或豆包实时语音（句中打断）【选型需实测核实】。
3. **点板追问**——点击板书任意一步，老师针对那步展开。依据 deixis 研究：教师指向板书元素建立表征间联结是核心教学机制（Alibali et al. 2014【强】；但冗余手势有害，Yeo et al. 2017，克制使用）。我们的 BoardScript step 结构 + qwen3-vl-plus / Qwen3.7-Plus 的 grounding（点坐标）天然支持。
4. **板演批改升级：红笔圈错 + 旁边示范**——反馈形态优先 **interpretive feedback**：把学生的方法可视化让他自己看见矛盾，而非冷冰红叉（Desmos 设计哲学【中】）；错误框定为"信息"不是"失败"（Shute 2008【强】：反馈聚焦任务、永不人格化评价）；指认具体错误步而非整题打回（Khan CLO：步骤级反馈是 LLM 时代才可工程化的反馈升级【中】）。**防坑**：VLM 过度纠正，判定走 L0 验算通道。
5. **老师记得我**（上下文复利的最小形态）——第二次课开场："你上次卡在分式方程漏检验，今天我们再看一道。"依据：Khan 实测喂入结构化学生历史 next-item correctness +3.4%、暴露未掌握前置技能先补 +2.7%，合计 +6.1%，是 A/B 出的最大杠杆【中】。

### L3 上下文层：学生模型（接口现在留，能力逐步上）

- 数据资产是**步级作答事件**（VLM 读学生板书的每一步）——这正是 BKT 设计用来吃的数据（Corbett & Anderson 1995【强】），也是我们相对纯文本产品的结构性优势。
- 起步用启发式（3 连对 + 无提示 = 掌握），成熟后换 pyKT/simpleKT（NeurIPS 2022 D&B 开源基准库）。
- 掌握概率驱动 fade：完整示范 → 补全例（AI 写一半学生接手）→ 独立题（Sweller 样例效应 + Renkl faded examples + Kalyuga 专业反转【强】）。

### L4 留存层（后续）

- 每日门槛压到极低续 streak、streak 与目标解耦（Duolingo 官方复盘：D14 +3.3%、7 天 streak 占比 +40%【中】）；
- "每一步都能看到进步"的路径可视化（洋葱【中】）；
- 抄机制前先问语境适配三问（Duolingo 前 CPO Mazal 复盘：照搬 Gardenscapes/Uber 均失败【中】）；
- 错题自动生成变式进间隔复习（变式教学 × Duolingo 错题复习合流）。

### 长期弹药库（归档，暂不实现）

> 注意：以下均为"教学法知识"，按宪法第 4 条——**不把任何一条手工编码成规则系统**。它们的存在形式是：写进讲解/批改模型的上下文（品味与意图），让步级数据积累起来，让强模型自己涌现这些行为。需要"系统"形态出现时才做的只有两件：数据结构与评测。

- 五级提示阶梯 pump→hint→prompt→示范（Wood & Middleton 1975 contingency【强】；Graesser EMT 同构【强】）——作为讲解模型的上下文原则，不写状态机；
- 先尝试后讲解 gating（Bastani PNAS 2025【强】；Kapur productive failure【强】）——这是行为/激励问题而非模型能力问题，但同样用上下文表达（"先看他试"），不做硬门控；
- 变式教学生成器：概念性变式（换非本质特征/反例）+ 过程性变式（一题多变阶梯）（顾泠沅青浦实验，国际同行研究最多的中国本土传统【中-强】）——LLM 生成变式是强模型天然能力，我们只需把错题数据留好；
- 教育数学内容重构：关键难点储备替代讲法（张景中"熟悉→简单→想通→直观"四检查点【中】）——长期内容护城河，这是人的品味资产，喂给模型而非绕过模型；
- 苏格拉底式深度对话——等用户用下来再融入，且必须有"直接告诉我"的降级出口（Khanmigo 用户抱怨实证【中】）。⚡ 明确**不做** SocraticLM/MathDial 式微调：那是弱模型时代对齐教学行为的手段，强模型 + 品味上下文即可达到，且随模型代际自动升级。

## 5. 落地路线

**Phase 1（即刻价值层，现在）**
1. 拍题开讲链路：图片 → PaddleOCR-VL/Qwen3-VL → BoardScript → 黑板开讲；
2. L0 验算通道接入 BoardScript 生成管线；
3. 板演批改升级：红笔圈错 + 旁边示范（interpretive feedback）；
4. 语音插话原型：打断-应答-断点续播状态机。

**Phase 2（上下文复利）**
5. 学生模型最小版：步级事件落库 + 结构化历史注入（"+6.1% 杠杆"）+ 开场记忆点；
6. 点板追问；
7. bansho 版面规划进 BoardScript（分区、不擦、故事线、整板截图复习卡）。

**Phase 3（长期效果层）**
8. 提示阶梯 + fade（样例→补全例→独立题）；
9. 变式生成器 + 错题间隔复习；
10. 留存机制（微 streak、进步可视化）。

**Eval 体系**：双轨——解答正确率（MathTutorBench 回归）+ 教学有效性（next-item correctness 离线近似 + 线上 A/B）；护栏：泄题率、数学错误率。
