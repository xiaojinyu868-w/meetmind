# 上课舞台的"惊艳"：要素、现状、怎么设计得更惊艳（2026-09-13）

> 问题：一个新用户（或目标用户）第一次用上课舞台，什么会让他惊艳？现有的东西还能怎么设计才更惊艳？
> 前提：惊艳不是特效，是**在用户预期之外、对他有用、而且每次都发生**的事。第一次看到会"哇"，第十次还在用，才算。能一次演示但做不到生产级的东西不算。
> 定义层见 `docs/AI_LESSON_DEFINITION.md`；本文是那八条判断在"第一印象"上的展开，属产品层，随迭代更新。

---

## 1. 惊艳的五种来源

| 来源 | 一句话 | 用户心里的话 |
|---|---|---|
| **快** | 比预期早发生 | "我还没点完它就开口了" |
| **懂我** | 内容明显是为我此刻这个问题、这个人做的 | "它知道我上周听过什么" |
| **超能力** | 做了人类老师和别的产品做不到的事 | "图居然会转，我拖它老师会跟着讲" |
| **被接住** | 我随时能插进去，它从那里接着来 | "我说等一下它真的等了" |
| **用心** | 每个细节都有人想过 | "这个笔尖、这个停顿……" |

五种里最贵也最难抄的是"懂我"（需要个人上下文与课堂现场，竞品没有），最容易做成特效的是"超能力"（所以每一项都要绑定有用）。

---

## 2. 惊艳的时间线：一个陌生人问"为什么圆的切线垂直半径"

理想的前 3 分钟，每个节拍标出现状与目标。

| 时刻 | 发生什么 | 现状 | 目标 |
|---|---|---|---|
| 0 s | 他在输入框敲完问题回车（或把一张题目照片拖到板上） | 输入框 + 开始按钮 | **拍题即开课**：照片落到板上的瞬间老师开口，无表单 |
| ≤1 s | 老师开口，第一句是钩子，不是"好的，今天我们来讲" | 首响 1–1.6 s ✓ | ≤1 s；声音一致（同一位老师） |
| ≤3 s | 板上第一笔——圆已经在长出来，老师还在说第一句 | 首笔 4–12 s | **≤3 s**：钩子后立刻出第一块 draw；开课那一刻按题目投机预取 |
| 10 s | 圆上一点 P 在动，切线跟着转，永远相切 | `time()` + `tangentAt` ✓ | 加**笔尖 / 手**跟着画；画面永远有一处在动 |
| 20 s | 老师："你把 P 拖一下"——滑块把手亮起，或者直接抓圆上的点 | 滑块 ✓；不能直接拖图上的点 | **直接操作**：图上的点、三维的视角都能抓；老师先拖一遍给你看再交给你 |
| 25 s | 他拖了。老师的声音**立刻**跟上："看，半径和切线的夹角一直是 90°" | 拖动只重算图，老师不知道 | **拖动 → 老师开口 ≤1 s**（区域预生成的短口播或快模型一句） |
| 45 s | 老师问："如果切线不垂直半径，会怎样？"——板下出现三个可点的选项 | `<ask>` 开放问题，要打字 / 说话 | **可点检验**：选项 / 点图 / 拉参数；选错的选项对应一种真实误解 |
| 50 s | 他点了错的那个。老师不说"错了"，**把他的想法画出来**："假设像你说的这样——看，这条线穿进圆里了，那它就不是切线" | 无 | **误解上板**：错误答案变成一张反例图，这是没有竞品做过的一手 |
| 70 s | 他插话："等一下，为什么一定穿进去？"老师停在半句，回到图上那条线重讲 | 打字 / 按钮打断 ✓；语音 barge-in 无 | 说"等一下"就停（三拍内），激光笔跳到他指的地方 |
| 90 s | 老师："你上周三那节课，老师讲到这里是这么说的——"**放了 6 秒他自己课堂录音**，接着往下 | 学习者切片进 prompt；课堂录音不进课 | **引用他自己的课**：收集线 × 课堂线，独有 |
| 3 min | 一个想法讲完，老师停下；板面安静，没有"生成中"，没有"老师没画出来" | 有系统自白文案 | 零系统自白（自信原则） |
| 课后 | 他收到一张 20 秒的"这节课"回放卡：板上的关键几帧 + 他拖了 3 次、答对 2/3；明天老师从他犹豫的地方开始 | 回看 ✓；回放卡无；跨课接续弱 | **一节课变成可分享的资产**，第二天"接着上次" |

这条时间线里，**竞品没有的**：拖动 → 老师开口、误解上板、引用自己的课堂录音、可转的三维、一节课的回放卡。**竞品有而我们要做得更好的**：可点检验（豆包是"按住说话才继续"，Khanmigo 是拖顶点 → 文本回应）、首笔时刻（VideoTutor 宣称秒级）。

## 3. 逐项设计：现状 → 竞品 → 更惊艳

### 3.1 开场
- 现状：表单 → 开始 → 1 s 开口 → 4–12 s 首笔。
- 竞品：豆包老师拍题 / 输入两种入口；VideoTutor 输入或截图。
- 更惊艳：**拖一张照片到板上就开课**（错题、课本、黑板照）；输入框只是备选。首句 ≤ 25 字钩子（已在 prompt），**首笔 ≤ 3 s**——开课瞬间后台按题目预取一张"封面图 / 第一张 draw"，老师的第一句话还没说完板上就在长。没有"正在生成"。

### 3.2 图（超能力的主体）
- 现状：`<draw>` 代码真值、`time()`、`param` 滑块、`trace`、`view3d`、手绘 / 工整、自动取景。
- 竞品：Khanmigo 生成可拖的图（顶点 / 线段），拖了老师文本回应；Brilliant 手工教具；豆包板书不可操作。
- 更惊艳：
  1. **直接操作**——图上标为可抓的点（`point(…, { drag: true })`）、三维的 yaw 直接拖、滑块只是兜底。
  2. **拖动 → 老师开口**——老师对你的操作有声音反应，≤1 s：先做"区域口播"（备课时为参数区间预生成 3–5 句：h<1 说什么、h>2 说什么），再做快模型即时一句。
  3. **老师先示范再交给你**——老师的手把滑块拖一遍（有语音），然后把手亮起来："你来"。
  4. **误解上板**——选错选项时，老师把那个错误的世界画出来（反例图）再指出矛盾。
  5. **图上作画的真照片**——真桥的照片上画力的箭头。
  6. **画面永远在呼吸**——每张图至少一处在动（trace 点、脉冲），板面不会像死掉。

### 3.3 检验（可点）
- 现状：`<ask>` 开放问题，学生打字或按住说话。
- 竞品：豆包"你理解了吗 → 按住语音回答才继续"；Khanmigo 苏格拉底式文字问答；Brilliant / Synthesis 每 20–30 秒一次可点。
- 更惊艳：`<ask>` 长出**答题动作**——选项（每个错项 = 一种误解）、点图（"切点在哪，点一下"）、拉参数（"把 h 拉到面积等于 2"）、填数。形态是**跟在板书下面的一行轻量 chips**，不是占满一屏的大卡（安静；不打断板面）。永远可以不答直接"继续讲"；自由输入与语音在旁边。选中即结构化信号进老师上下文（`boardNote` 通道）。

### 3.4 打断与指
- 现状：文字 / 按钮打断；点板上任何东西 = 引用它问；激光笔按句对齐。
- 更惊艳：**语音 barge-in**（说"等一下"就停，三拍内接话）；点公式的某一行 = "这一步没懂"（无需打字）；老师重讲时上一版推导**折叠**而不是消失（板有历史）。

### 3.5 懂我
- 现状：掌握轨迹 + 理解半进 prompt；课堂录音、错题、收藏不进课。
- 竞品：都没有你的课堂。
- 更惊艳：**引用你自己的课**（放 6 秒你老师的原声，或引一句转录）；**例子从你的收藏来**（上周收的那篇文章 / 你拍的那道题）；老师叫你的名字；第二节课从你上次犹豫处开始并说出来。

### 3.6 声音与节奏
- 现状：qwen3-tts flash + 教学语气指令，按句预取；语速 1× / 1.25× / 1.5×。
- 更惊艳：标签驱动的语气（揭示处提速、关键步慢下来、停顿是内容）；**同一位老师**（声音、名字、口癖跨课一致，分身线可接）；**笔的声音**——轻微的马克笔摩擦音与笔迹同步（可关；这是"有人在画"最便宜的证据，几乎没人做）。

### 3.7 课后
- 现状：回看重放、课堂记录、事件日志。
- 更惊艳：**回放卡**（20 秒：板上关键几帧 + 你的操作与答题）——可分享，是"回声卡"在上课线的形态；讲过的内容自动进复习与出题；**跨课接续**由老师说出来。

### 3.8 用心（安静的惊艳）
笔尖与缓动、KaTeX 与图同色、纸面质感、页签、手绘开关、暗色、reduced-motion；**零转圈、零"生成中"、零系统自白**——等待用声音填（老师先说钩子），失败只进老师上下文。

## 4. 生产级的含义

"哇塞"要每次发生，所以每一项都带门禁：
- 图：draw 报错率 < 5% 且自愈在展示前完成；首笔 ≤ 3 s（p50）、≤ 8 s（p90）。
- 交互：可点检验应答率 > 60%；拖动 → 开口 ≤ 1 s；打断 → 首响 ≤ 1.5 s。
- 声音：首响 ≤ 1 s（p50）；音画偏差 < 300 ms；连续静止 < 15 s。
- 自信：板上系统自白 0。
- 成本：≤ ¥10 / 小时。
- 回归：live eval（`tests/eval/`）+ 真课 e2e 截图每轮跑。

## 5. 复核（2026-09-13 傍晚）：对照四条原则重排

复核的四条原则：**先表面效果与交互，再深入内容层**；**效果能不能做到预期**；**简洁、专注、关键处极其好**；**Bitter Lesson**（给模型能力与渲染契约，不给规则）。

### 5.1 关键处只有一个：一张会动、能摸、会回应的图，加一个声音

现在的课"和大模型直接输出没什么区别"，原因不在模型，在板：板是一列竖着堆的排版块（要点、公式、字幕），图是配图；口播把文字念一遍——这就是被朗读的 markdown。要让它一眼看出不是大模型输出，主媒介必须换成**变化中的图**：字少、图多、每个想法都有一处在动、学生的手在图里、老师对他的动作有反应。文字退到标签与一句结论，话交给声音。这是表面效果层的上限所在，其余一切（懂我、回放、barge-in）都排在它后面。

### 5.2 逐项复核

| 决策 | 层 | 可行性 | 简洁 / 专注 | Bitter Lesson | 结论 |
|---|---|---|---|---|---|
| 首笔 ≤ 3 s | 表面 | **有把握**：TTFT ~0.9 s，短 draw 块 ~1 s 流完，算图 ms 级；需要契约"第一块小、后续 into 追加" | 是 | 契约（延时），不是内容规则 | A 期 |
| 视觉优先的板（字少图多、每个想法一处在动） | 表面 | **有把握**：是 prompt 契约 + 渲染层（字幕承担文字）；模型已能写 time() | 是 | 给的是"板有多大、文字在哪呈现"的物理事实 | A 期，首位 |
| 镜头（zoom / pan 到某处） | 表面 | **有把握**：SVG viewBox 可用 SMIL 动画；时间轴编译器加一个属性 | 一个原语 | 能力 | A 期 |
| 连续变换 / 3D 可拖 | 表面 | **有把握**：time() + lerp / view3d 已有；yaw 绑到拖动 | 一个原语 | 能力 | A 期 |
| 直接操作（拖图上的点 / 视角） | 交互 | **有把握**：param 已有；拖 = 60 fps 改 param 重跑（runDraw ms 级，Worker 往返 ms 级） | 一个原语（drag） | 能力 | A 期 |
| 拖动 → 老师开口 ≤ 1 s | 交互 | **有风险**：预合成"区域口播"可到 ≤ 1 s（TTS 缓存），快模型即时一句 ~2 s；模型能否写出好的区域口播待实测 | 一个原语（区域） | 能力 | A 期，先做预合成 |
| 可点检验（chips） | 交互 | **有把握** | 是 | option 是自由内容的容器，不是题型模板 | A 期 |
| 误解上板 | 交互 + 内容 | **有风险**：模型要为错项预写反例图（每项 100–300 token），质量待实测；退路是选中后一次微轮 | 是 | 能力（option 可带 draw） | A 期，实测后定 |
| 公式"写出来"的揭示 | 表面 | **有把握**：MathJax SVG 路径逐笔描（排版字体，非手写）；真手写（DiffMath）后置 | 是 | 渲染 | A 期后半 |
| 笔尖 / 手 / 笔声 | 表面 | 手 **不确定**（可能像廉价白板动画，要看了再定）；笔尖已有；笔声易做可关 | 手有噪音风险 | 渲染 | 笔尖保留；手、笔声做成开关先试 |
| 零系统自白 | 表面 | 有把握 | 是 | — | A 期，立即 |
| 引用你自己的课 / 跨课接续 | **内容** | 有把握但工程量中（转录检索 + 片段播放） | 是 | 上下文 | **B 期** |
| 备课预取 / 审核复算 | 内容 | 有把握 | 是 | 上下文 | B 期 |
| 语音 barge-in | 交互 | 有风险（ASR + VAD 延时） | 是 | — | A 稳后 |
| 回放卡 | 表面产物 | 有把握 | 增加面 | — | **延后** |
| 图像三源 / 图上作画 | 表面 | 有把握（检索 / 快模型） | 增加面 | 能力 | 真图作底可作 A 期一小步；三源整体 B 期 |
| 虚拟同学 / 数字人 / 实时视频 | — | — | 破坏简洁 | — | 不做 |

### 5.3 重排后的顺序

**A 期 · 表面效果与交互（把关键处做到极其好）**
1. 板的视觉语言换掉：视觉优先契约 + 首笔 ≤ 3 s + 零自白（prompt + 前端；一轮）。
2. 图的表现上限：镜头、连续变换、3D 可拖、公式写出来——四个正交能力，每个都对应时间线里的一个"哇"。
3. 触摸：直接操作 + 拖动 → 老师开口（区域口播预合成）+ 可点检验 chips + 误解上板（实测定）。
4. 用心项做成开关先试：手、笔声。

**B 期 · 内容层**：引用你自己的课、跨课接续、备课预取、审核复算、图像三源。

**C 期 · 稳了再说**：语音 barge-in、回放卡。

### 5.4 简洁的守门

`<draw>` 每加一个原语都要能指到时间线里的一个节拍；A 期只加四个（camera / drag / 区域口播 / option 带图），不加第五个。板上同时出现的东西以"一个想法一张图"为单位，多了就翻页。文字只做标签与一句结论。
