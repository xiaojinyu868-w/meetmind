# Landing Product Film

> MeetMind 首页桌面产品宣传片的创意、拍摄、ChatCut 剪辑和验收合同。影片必须是真实产品操作驱动的连续电影，不是截图轮播、功能列表或旁白覆盖的幻灯片。

> 状态：v12 制作合同。当前 Landing Page 仍使用旧成片，只有在本合同全部验收通过后才能替换正式资源与相关说明。

## 核心命题

**把每一次学习，接成一条不会断的线。**

用户心智始终是：**真正听过课、了解你正在学什么的 AI 同学。**

影片讲清两条互相回流的主线：

1. **收集场景**：像发消息一样收下文字、语音、图片、网页、文件和想法，模型在后台判断它与哪门课、哪个目标和哪个问题相关。
2. **课堂学习主线**：录下一节课，课中 AI 同桌跟上现场，课后基于真实证据解释和练习，多节课继续形成单元与考试范围。

个人上下文不是第三条用户工作流。它只在结尾作为两条主线已经相连的结果出现，用户不需要管理标签、数据库或画像。

## 成片规格

- 只制作桌面横版主片，不再制作手机竖版。
- 时长目标 `55–58 秒`，上限 60 秒。
- 画布 `1920×1080`，`30fps`，H.264 高码率交付，同时保留可编辑 ChatCut 项目。
- 真实产品画面以完整桌面构图为主；有明确动作对象时才进入近景，近景结束必须自然回到完整现场。
- 默认静音自动播放时，画面和字幕仍能独立讲完故事；用户开启声音后得到完整旁白、音乐和动作声音设计。

## 58 秒连续叙事

| 时间 | 章节 | 必须拍到的真实动作 | 叙事任务 |
|------|------|--------------------|----------|
| 0–4s | 命题 | 无产品 UI 的品牌空间对象由分散资料汇成一条线，随后匹配切入真实收集输入条 | 建立影片自己的视觉语法，不用静态标题卡开场 |
| 4–13s | 收集 | 输入一条想法；粘贴网页；放入图片/PDF；启动一次语音收集；不同材料进入同一收集流 | 第一眼证明可以收文字、语音、图片、网页和文件 |
| 13–23s | 课堂 | 选择麦克风/电脑声音；开始课堂；真实音频驱动转录、课堂脉络与 AI 同桌同步出现；轻问一个与现场相关的问题 | 证明 MeetMind 真的在听同一节课，而不只是课后处理文件 |
| 23–30s | 下课不断线 | 点击“结束这节课”；同一课堂自然收束并进入三栏课后复习 | 建立课中到课后的连续性 |

| 54–58s | 回流与收束 | “最近学习现场”短暂出现；完成成果旁显性分享入口；品牌空间对象重新合拢成 MeetMind | 证明两条线已经相连，并把能力收回品牌命题 |

## 旁白草案

> 学习真正困难的，从来不是记下一次答案，而是让每一次经历彼此相连。文字、语音、图片、网页、文件和一闪而过的想法，MeetMind 都先替你收下，再判断它与哪门课、哪个问题有关。上课时，它跟着老师一起听，原话、板书和课堂脉络同时向前。下课后，解释从真实证据开始；每一道练习，都能回到老师讲过的那一刻。你可以用闪卡记住，用测验验证，用导图看清结构，用信息图、播客和速查表换一种方式继续。几节课连成单元，一个单元走向考试。MeetMind 不只是记得内容，它逐渐了解你正在学什么，也把你每一次努力，接成一条不会断的线。

正式配音前必须用最终画面节奏重新断句；旁白不能为了塞满功能而持续加速。

### 拍摄节奏

- 原始操作速度以“熟练用户”为准；输入后 250–500ms 内进入下一动作，不保留寻找按钮、犹豫或等待模型的无信息时间。
- 所有模型等待拆成“触发动作 → 有意义的准备态 → 结果落地”，剪辑时压缩等待但不伪造结果。
- 鼠标移动走短弧线，目标到目标之间一次到位；不要来回修正、悬停阅读或在无信息区域绕行。
- 每个动作前后各保留至少 12 帧干净把手，供 ChatCut 做匹配切、遮罩和声音前置。
- 浏览器只使用 Codex 内置浏览器完成产品操作，不接管用户正在使用的 Edge。

## 统一镜头语言

整片只使用一个视觉母题：**朱批色证据节点沿墨绿上下文路径向前移动。**

- 每次材料进入、课堂开始、结束课堂、提交答案、证据回跳和打开应用，都由同一个证据节点完成视觉接力。
- 大章节切换使用 8–14 帧的“路径掠过”遮罩：墨绿细线先进入，朱批节点经过动作焦点，下一场景从节点后方展开。
- 同一对象跨界面时优先匹配切：输入条 → 课堂时间线；课堂停止按钮 → 课后三栏边界；测验依据圆点 → 转录时间点；导图根节点 → 考试范围中心。
- 允许三种景别：完整产品现场、动作对象近景、结果全景。每次近景都必须由真实点击进入，并在动作完成后回到现场。
- 禁止随机缩放、持续 `zoompan`、故障特效、3D 翻转、无意义景深和每个章节换一种转场。

## Motion Graphics 清单

所有 MG 在 ChatCut 中保持可编辑，不烘焙成不可修改的假产品界面。

1. `Context Object — Open`：0–4s 的三层空间对象，分别代表课堂现场、收下的材料和个人学习线。
2. `Evidence Path — Transition`：整片复用的细线与朱批节点路径转场，允许改变路径但不改变视觉语法。
3. `Chapter Label`：只在首次进入“收集”“课堂”“有根复习”“走向考试”时出现，每次不超过 1.2s。
4. `Six Methods Spine`：六类学习方式出现时，用同一条路径依次点亮六个学习动作，不覆盖真实应用矩阵。
5. `Context Object — Close`：结尾把课堂、材料和长期理解重新收束成 MeetMind。

MG 不使用大面积黑色字幕条；字幕、标题和证据标注必须避开真实交互焦点。

## 声音设计

- 完整中文旁白使用 `qwen-audio-3.0-tts-plus` 的 `longanlingxin` 系统音色，成熟、克制、温暖；按最终时间线分段生成但听感必须是一条连续表演。
- 课堂段保留 2–3 秒真实试听音频，在旁白句间露出，给“真的听过”听觉证据。
- 音乐只用一条连续音乐床：低密度纸张/木质质感、克制脉冲、无企业宣传片式上扬弦乐；收集段轻，课堂段形成稳定节拍，证据回跳时短暂留白，结尾不做夸张高潮。
- 证据节点拥有一个贯穿全片的短促有机音色；同一音色在材料进入、提交和证据跳回时做音高与长度变化，形成听觉识别。
- 点击声只保留有叙事意义的动作：开始课堂、结束课堂、提交答案、跳回依据、打开导图、完成收束。禁止给每次鼠标点击都加音效。
- 旁白峰值、音乐床、真实课堂与 SFX 必须分轨混音；字幕打开/关闭不影响声音结构。

## 字幕合同

- 使用原生字幕轨，简体中文，最多两行。
- 字体 `Noto Sans SC`，常规句子不大于 42px；米白半透明底、墨绿色正文，不使用描边、重阴影或逐字彩色高亮。
- 字幕服务于静音观看，但不重复画面上已经清楚显示的按钮文字。
- 品牌名统一写作 `MeetMind`，不得被 ASR 拆成 `meet mind`。
