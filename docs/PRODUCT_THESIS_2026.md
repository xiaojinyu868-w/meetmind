# MeetMind Product Thesis 2026

> **好的输出 = 个人上下文 + 场景上下文 + 好的模型智能。**

这份文档是 MeetMind 的产品判断基线。新功能先回答：它是否在自然地补全用户上下文，或者帮用户发现与当前目标更相关的信息？

## 1. 产品定位

MeetMind 是以学习者长期上下文为中心的 AI 学习产品。

用户照常听课、收藏、整理、提问和使用学习工具。MeetMind 一边理解“这是怎样的学习者”，一边理解“眼前这个学习现场发生了什么”，再让模型判断此刻最值得做什么。

不要求用户选人群、设标签、配数据源或安装插件。个性化应从使用产品的过程中自然长出来。

## 2. 核心模型

**上下文 = 个人上下文 + 场景上下文。**

**好的输出 = 个人上下文 + 场景上下文 + 好的模型智能。**

这是产品心智模型，不是字面上的算术。三部分分别承担不同职责：

|  | 个人上下文 | 场景上下文 |
|---|---|---|
| 回答的问题 | 这是怎样的学习者 | 此刻具体发生了什么 |
| 内容 | 目标、阶段、长期困惑、掌握情况、学习节奏、收藏、行为与反馈 | 某节课、某篇文章、某道题或某次讨论的原件、转录、资料、进度与即时意图 |
| 时间尺度 | 跨天、跨课、长期累积 | 围绕一个具体学习现场，有明确边界 |
| 分享边界 | 默认私有 | 可在用户明确分享时形成场景快照 |

模型智能负责在两类上下文中理解意图、辨别证据、建立联系，并决定此刻应该解释、定位、复述、检验还是保持克制。模型不能弥补缺失的真实上下文；上下文也不能代替模型的判断能力。

信息流是这一模型的一个具体应用：

**推荐方向 = 个人上下文 × 当前目标 × 真实外部证据。**

只有上下文，信息流会变成兴趣消费；只有目标，信息流会变成僵硬的任务清单；没有真实外部证据，则会变成模型编造的资料。三者同时存在，才能判断“这条内容现在对这个人是否有用”。

## 3. 两条产品主线

### 3.1 收集线：沉淀零散的日常上下文

用户的学习不会只发生在一节正式课堂里。微信里收到的文章、随口说的一段语音、拍下的书页、临时收藏的链接和一句没想明白的问题，都应该先被低摩擦地接住。

收集线的用户心智是：**“我先随手发给 MeetMind。”**

这些碎片保留原件和来源，并通过后续整理、追问、使用与反馈，逐渐沉淀为长期个人上下文。它们也可以在需要时被挂回某节课，成为场景上下文的补充材料。

### 3.2 课堂线：以一节课为理解单元

课堂线的用户心智是：**“帮我真正理解这一节课。”**

一节课是最小的完整理解单元。MeetMind 围绕它保留原声、转录、课件、板书、提问、标记和练习结果，并区分课中“跟上”与课后“回看、练习、连接”的不同节奏。

内容按学习结构继续向上组织：

```text
原声 / 课件 / 板书 / 提问
  → 一节课（最小完整理解单元）
  → 课程单元或章节（相关的多节课）
  → 一门学期课程（多个单元）
  → 长期个人学习上下文
```

两条线互相回流：收集内容可以补充课堂，课堂中的困惑、掌握变化和练习反馈也会更新个人上下文。

## 4. 三层能力结构

1. **收集层**：课堂、文章、视频、图片、语音和想法。
2. **工具层**：总结、闪卡、导图、测验、对话等按需使用的工具箱。
3. **智能层**：从累积上下文中发现内部关联，并自动检索、筛选外部信息。

工具箱与信息流不是两个产品。工具层产生更深的上下文，智能层让工具处理过的内容继续产生价值。

### 多来源不是频道，而是证据

MeetMind 不把微信、知乎、B站、论文站做成一排内容频道。平台只是来源证据，组织中心仍是用户当前上下文和目标。

每条收集都保留两层来历：

- **怎么进来的**：速记、文件上传、课堂录音、微信发来、分享领取。
- **原始出处**：平台、作者/发布者、canonical URL、发布时间、提取方式。

正文状态必须诚实区分：正在读取、正文完整、只有摘要、只有原链接、读取失败。只有完整正文能支撑完整观点；摘要只能支撑有限判断；只有链接时不得让 AI 猜测原文。

同一个 canonical URL 不因跟踪参数、微信转发或换设备而重复生成 capture。解析失败时保留原件并允许以后自动补全，不把恢复成本转嫁给用户。

## 5. 信息流规则

- **有根据**：每条推荐能说明来自哪些收藏，对齐哪个目标。
- **有增量**：不重复用户已经收下的内容，必须带来新证据、新观点或新路径。
- **有选择**：少而准，没有足够好的内容时宁可不推。
- **有反馈**：“有用”和“不相关”要回写上下文，改变之后的选择。
- **零配置**：外部检索、去重、质量筛选和排序由 MeetMind 完成。
- **真实来源先于解释**：外部卡必须先有可打开的网页、论文或图书目录记录，AI 只能排序和解释，不能生成资料。
- **主动打开边界**：每轮信息流既沿当前目标深入，也保留与问题相关的相邻方法或不同立场；“跳出茧房”不是随机内容。
- **内容形态有配比**：有足够高质量候选时，外部流至少包含一条论文或书籍，以及一条不同视角；检索失败宁可少推。

## 6. Taste

- 像一个了解你近况的编辑，不像无限下拉的内容平台。
- 先给“为什么是它”，再让用户点开。
- 不用人群标签代替对真实上下文的理解。
- 不用丰富卡片掩盖推荐质量不足。
- 用户不应感知数据源、模型选择和后台降级。

## 7. 核心指标

北极星指标：**每周被用户判定有用，并产生后续行为的推荐数。**

后续行为包括打开原文、收藏、追问、用工具处理或回到相关原始内容。曝光量、卡片数和无目的停留时长不是成功指标。
