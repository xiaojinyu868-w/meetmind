## 二、MeetMind 是什么

**一句话**：用户像发微信一样把学习现场发给 MeetMind，先收下，后台慢慢理解，理解成熟后自然长出同桌、回声、复习、Tutor。

**当前聚焦**：课堂场景。大学生录一节课 → MeetMind 当场作为 AI 同桌陪他听 → 课后基于真实意图帮他解释、定位、复述、验证，生成闪卡/测验/速查表/思维导图/学习报告 → 生成一张让他忍不住分享到班级群的回声卡。

**产品哲学**：
- 上下文产品 = 场景上下文（课堂内容，班级可共享） + 个人上下文（学习特质，私有积累）
- 安静是底色，智能是主角
- 每句话都能指回真实原件，引用能跳回 `[MM:SS]` 转录

**对标竞品**：
- Thetawave（WT 校友产品）
- Hyperlow（很火的 AI 教育产品）
- 功能体量已与这些大 ARR 产品接近，局部细节体验已差不多

## 四、用户与获客现状

### 用户画像
- 本科以上、文科为主（理科公式识别尚未完全攻克，依赖用户手动拍照补全）
- 有紧迫任务：考研、期末考试
- 需要课堂录音 → 课后整理 → 考前速查的完整闭环

### 当前用户来源
- 黑客松现场推广获得几百个体验用户
- **留存很低**：用一两次就不用了

### 留存低的三个猜测
1. 黑客松用户不是真实目标用户（他们是尝鲜者，不是要考试的人）
2. 产品钩子没做好，没勾住用户
3. 缺乏真实使用场景的内容传播（竞品用真实体验视频 + 小红书投放，我们没做）

### 获客能力自评
- **获客是我最不擅长的**（排序：产品设计开发 > 运营 > 获客）
- 对流量没有掌控感，之前让团队成员做小红书数据难看
- 没有做过成功的自媒体获客经历
- 知道标准答案（KOL/KOC/内容/社群），但没跑通过

## 五、团队现状

### 历史脉络
- 最初 3-4 人 → 逐步退出 → 现在自己 1 人开发
- 现有 4-5 个有意向加入的伙伴，但还没想好怎么定位和分工
- 如果想找人，可以轻松构建十几人团队，但不知道怎么做好一支团队

### 上一段创业失败的总结
| 失败原因 | 具体表现 |
|---------|---------|
| 超级个体包办 | AI 让我一个人能干获客/宣传/开发/见投资人，成员只是打下手的角色 |
| 成员没有参与感 | 给一个人负责技术，但我比他做得更好就自己上；给一个人负责增长，也没参与感 |
| 成员对产品理解不深 | 别的团队的非一号位都能讲出产品核心，我的成员讲不出来 |
| 选人问题 | 选同级学生（清华同学），他们面临更多诱惑（实习/期望薪资高），自然退出 |

### 当前困惑
- 有新人想加入，问我"我能为团队做什么"，**我答不上来**
- 我脑子里没有"已定义的、可以交给别人的、有验收标准的工作包"
- 倾向于自己上手因为"沟通成本 > 自己做"，陷入了局部最优解

## 六、我带来的三个问题

### 问题 1：获客
- 知道标准答案（自媒体/社群/渠道/PMF/自传播），但没跑通
- 对流量没有掌控感，不敢开始
- 猜测：黑客松用户不是真实用户，需要找真正要考试的人
- **真正的 gap**：还不知道产品对真实目标用户的价值是否成立

### 问题 2：产品
- 功能体量已经够了，但产品"有点大了，是不是可以拆开"
- 需要找到一个单点钩子作为获客入口
- 桌面端和移动端定位不同（桌面 = 整合工作台，移动 = 随手拍/录音）
- **真正的 gap**：还没有一个真实付费用户验证产品价值

### 问题 3：组织
- 有意向加入的人，但不知道怎么定位、分工、验收
- 上一段创业的组织失败经验还在，不想重蹈覆辙
- 倾向于找学弟学妹（有认知差、可提供成长价值），但只是猜想
- **真正的 gap**：脑子里没有"可以交给别人的工作包"的定义

## 七、我自己梳理后的思考

### 三个问题的关系
这三个问题不是并列的，是有先后顺序的：

```
先有一个真实付费用户（验证产品价值）
  → 基于真实使用打磨获客钩子
  → 基于获客需求定义工作包
  → 基于工作包搭建组织
```

**核心判断：我现在不需要更多方法论，需要的是"用一个真实用户验证一次"。**

### 关于"做成"的里程碑定义

| 阶段 | 指标 | 时间预期 |
|------|------|---------|
| 最小做成 | 1 批稳定的付费用户 | 近期 |
| 第二里程碑 | 自媒体有正向流量 + 用户主动要求新功能 | — |
| 第三里程碑 | 收入能养活团队，给核心人员开得起工资 | — |

### 关于现金流
- 软件付费是主线
- "软件 + 咨询服务"做现金流的想法暂时搁置（服务会占用我最稀缺的时间）
- 融资也在考虑，但软件融资当前较难
- 先把软件正循环跑出最小版本

## 八、我期待从私董会带走的

**不是标准答案**（获客渠道、PMF 方法、组织架构这些我都知道标准答案）。

**我想要的是**：

1. **针对我当下阶段的具体行动路径**——不是"做什么"，而是"先做哪一件事、怎么验证、下一步根据结果往哪走"
2. **从超级个体到组织搭建者的转变经验**——在场有已经做成团队的同学，我想知道你们当时是怎么跨过这个坎的
3. **对"我答不上来新人能做什么"这个问题的解法**——是先想清楚工作包再找人，还是先有人再一起定义工作？
