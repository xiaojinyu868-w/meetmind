# MeetMind 1.0 发布更新日志：这四个月我们做了什么

> 2026.04.02 – 2026.08.07 · 253 次提交 · 网页 / 桌面端 / 微信三条线
> 这是一份用户向的更新记录：讲人话，但不回避我们真正做过的技术功课。

---

## 四月 —— 课堂线起步，AI 同学学会"用工具"

**录一节课，就有同桌**
- 课堂录音实时转写上线，课中就能向 AI 同桌提问（4.2）
- 桌面端侧边栏导航 + 视频复习布局（4.10）
- 视频复习播放器通用化：不再绑定单一视频源；新增学习报告产物（4.13）

**Tutor 完成 Agent 化改造**（4.14，单日 13 个提交）
- AI 同学从"一次性问答"升级为**会自己调用工具的 agent loop**：需要查转录原文就查原文，需要联网就自己发起 web search
- 思考过程实时可见：每一步工具调用都有轨迹，回答逐字流出
- 三层路由把**首字延迟从 60 秒压到 1 秒以内**
- 免登录也能试用 AI 同桌，降低第一次体验的门槛

**课堂体验密集打磨**
- 思维导图随课堂生长、关键内容提前预感（4.18）
- ASR 热词注入：你的课表和专有名词直接进入识别上下文（4.18）
- 课堂 v2 信息架构 + 编辑器感排版（4.18）
- ASR 语言模式、转写 prompt 分段、幻觉过滤——专有名词和"一本正经的胡说"同步收敛（4.22）

## 五月 —— 质量工艺月：ASR、Tutor、设计系统三条硬线

**ASR 做到"飞书妙记级"**（M2 / M5 / M8）
- 识别稳定性专项治理 + 上下文热词偏置 + 三段式渲染
- **中英文混讲（code-switch）识别**：老师中英夹杂不再乱成一团
- 静默纠错闭环：识别错的地方后台自动修正，热词自动聚合并回注

**Tutor 骨架升级**（M3 / M10）
- 接入 Vercel AI SDK v6 agent loop，工具调用稳定可控
- 三个对话入口收口为一个 mode 驱动的统一端点——之后所有模式在同一底座上演进

**课中 AI-native 三件套**（M7）
- Skill chips：课中随时唤起具体学习动作
- 划词就地解释、英译中内联气泡（可开关）

**可观测性与回归护栏**（M1）
- 全链路结构化日志 + 错误追踪；SWE-Bench 风格 eval harness——之后每次改 ASR / Tutor 都有数字说话

**应用矩阵逐个收敛**（5.31，PR-1~8）
- 闪卡、测验（多题型 + 严控干扰项）、思维导图（收敛为单课形态）、课堂播客（时长上限）、信息图重做为"一张图带走这节课"
- 考前速查表支持横向 A4 打印、单条删除、区块折叠

**设计系统 v7，七轮重做**（5.31）
- 前六轮是机械替换，第七轮把 7 个"用户第一眼看到"的页面真正重做：pine / 朱批双签名色、衬线斜体点缀、等宽字体眉标、AI 在场的呼吸光感

**分享 v3.0：把一节课递给同学**（SharedAgent）
- 录课结束自动就位分享入口；同学打开链接第一眼看到真实产物（速查表色块 / 导图分支 / 第一道题），而不是一行介绍文字
- 同学无需登录即可基于这节课向 AI 提问；领取后自动进入自己的学习空间
- 你有管理面：每个分享的打开 / 对话 / 领取计数，可随时撤销
- 隐私是硬边界：**分享的是课堂内容，你的个人画像永远不出域**；撤销接口对非所有者返回 404，不暴露存在性

**默认模型接入阶跃星辰 StepFun**（5.30）
- 全链路默认切换 `step-3.7-flash`，DeepSeek / 通义千问保留为可选
- 同日做了次"感知速度"专项：转录注入从整节课 25–35k tokens 截到 8k 字窗口、流式输出按词平滑——复习态对话首字从 3–10 秒降到 0.5–2 秒

## 六月 —— 底座收口与速度战役

**「聊聊你想要的」：目标共建上线**（M11）
- 旧的硬编码问卷被一次对话取代：像和教练聊天一样定下这学期要学什么，支持传文件、发语音、甚至直接打电话聊
- AI 提炼出"我听到的是…"卡片，可编辑再保存——目标从此进入每一次对话的上下文
- 实时语音通话同步升级：semantic VAD 能分清"嗯嗯"的附和和真正要说话，近场降噪，嘈杂环境不再频繁误打断

**个人上下文进入所有模式**（M11.4 / M11.5）
- 你的目标、阶段、长期困惑（bio）注入课堂同桌、复习、全局问答等全部对话模式

**ChatBase：六个对话面板收口到一个底座**（M12 / M13 / M14.5）
- 代码高亮（Shiki）、Mermaid 图、图片预览、富文本+纯文本双格式复制、大段粘贴保护、字数提示、消息点踩/点赞反馈——一处做好，处处受益
- 课堂同桌 AI-native 重做：稳定的动态 chip 取代了旧的 inline app 横条（M14）

**速度战役：TTFT 压到底**（M13）
- 麦克风即按即录；默认模型切阿里云原生 qwen3.7-plus
- 首字延迟**中位数 1107ms，p50 再降 55%，p95 降 32%**——每一次对话都快在明处

**跨设备同步 T1/T2**（6.4）
- 转录数据上云、换设备登录自动回填；录音音频上云持久化 + 流式服务——手机上录的课，电脑上接着复习

**公众号文章接入**（6.8）
- 微信里看到的好文章，绕过反爬直接进入你的收集线

**一堂 prompt 哲学课**（6.1）
- 按《提示词设计哲学》重写全部 10 处学习应用 prompt："描述目标，不描述路径"
- 附带效果：闪卡 180 秒超时崩溃修复，prompt 输入量降 70%，模型越强产出自动越好

## 七月 —— v4.0 全端采集层：最密集的一个月（132 次提交）

**桌面端从 0 到开放下载**（desktop v1.1 → v1.3）
- Electron 桌面壳：**loopback 系统音频录网课，不需要任何会议机器人**（Windows WASAPI / macOS SCK）
- 桌面小窗：随手记、随口问（流式）、截图快捷动作，失焦自动收起
- 全局热键：录屏课时截图挂课堂时间轴，否则收进收集线（⌘/Ctrl+Shift+M）；⌘/Ctrl+Shift+K 随时唤起小窗
- 自动更新检查 + CI 打包分发（mac dmg / win nsis）+ 官网开放下载

**Octo Buddy 桌宠，四次迭代**
- v3 参数化生命感：呼吸、随机眨眼、眼随光标、拖拽果冻物理、贴地阴影、深夜自己入睡——原画 100% 保留，生命感全来自连续参数
- v3.2 交互定型：单击随手问 / 双击旁听网课 / 拖图片收下 / 右键菜单
- v4 全矢量重构，形状命中——只有身体吃点击，透明区域全穿透

**课中「截取这一页」**（7.28）
- 主动截图挂在课堂时间轴上，与转写严格同轴；课后复习按时间轴看到缩略图，点击跳回那一刻
- 桌面热键和课中按钮走同一条链路；跨设备自动补齐

**标题系统 + 课后理解**（7.28）
- 课堂列表告别满屏"录音 14:32"：每节课自动生成「主题 · 课程 · 日期」标题，零信息词宁可不生成；你手动改过的名字永远不会被覆盖
- 课后定稿一次 LLM 调用同时产出标题、摘要、精选（替代过去 3–4 次全文复读）

**teach-back「讲给同桌听」**（7.27）
- 应用矩阵第 7 个应用：你把刚学的内容讲一遍，AI 按覆盖度告诉你哪里讲漏了、哪里还不稳——以教促学进入产品闭环

**微信链路完整落地**
- 公众号带参二维码扫码登录 / 绑定（7.18）
- 微信 Agent：绑定后直接发文字消息和 AI 同学对话，它带着你的画像和近期收集回答，客服消息异步送达（7.27）

**产品与体验面**
- 首页学习控制台重做 + 首次进入路径（7.14）；Feed 偏好系统、移动端收集卡片改版、capture 来源溯源
- 复习体验：音频波形三层加速（服务端预计算 + 本地缓存）、复制 AI 回答自动去时间戳
- 分享落地页重设计：产物展品卡当主角、思维导图真渲染
- 官网四线叙事重构 + 技术介绍页 + 桌面端下载区开放
- 图像生成切换 DashScope：qwen-image-3.0-pro 优先，自动降级兜底

**月底质量基线**
- **899 个自动化测试全绿**；ASR 平均 CER **1.22%**；Tutor 评测通过率 **92.9%**
- 一次五路分片审计修掉 25 个文件的问题（含截图按钮断链、越权访问等 P0/高危项）
