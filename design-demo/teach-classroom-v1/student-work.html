学生产出上板

学生昨晚拍了一道卡壳的作业题。课上老师把它贴上黑板，用红笔现场批改——AI 讲的是学生自己的东西，不是题库里的例题。

交互触发与状态转移

  • 学生拍题（课前或课中）→ 照片飞入贴上黑板（胶带拍立得，微微歪斜）
  • 老师端详 → 注视虚线框停在出错的行上
  • 红笔逐笔批注：圈出错误行 → 给正确步骤打勾 → 答案行画波浪线 → 写批注「车 5 s 就停了」
  • 小结气泡锚定在照片旁；批注与照片一起进入课后复习材料（见 06）

关键决策

  • 照片保留「纸」的质感（胶带 / 歪斜 / 阴影）——它是学生物件，不做成 UI 卡片
  • 红笔 = 朱砂签名色在课堂的物化：老师批改用朱砂，板书正文用粉笔白
  • 备选：把照片 OCR 成文本重新排版上板——本稿否决，抹掉笔迹就抹掉了「这是你的作业」
