SCENE 03 · WAITING

等待在叙事里

老师判断「该让学生看见运动了」，需要调用 lab-sim skill 构造实验——这需要几秒。这几秒里老师不停课：先开口铺垫，板上的实验台随讲述逐笔搭起来。

状态转移

  • 深想开始 → 口播铺垫「我构造个实验，稍等」+ 板右侧出现建设中区域（呼吸点标记）
  • skill 逐步就绪 → 斜面 → 角度 θ → 小车 → 刻度尺 →「放手！」，每一笔配一句口播
  • 就绪 → 建设中标记熄灭，实验接入课堂（见 05 实验小部件）

铁律

  • 等待永远包装在叙事里：绝不出现 spinner / 「生成中」/ 进度条
  • 等待时长 = 老师自言自语的时长，板面始终有东西在长
  • 学生此时可以按住插话——等待不锁交互
