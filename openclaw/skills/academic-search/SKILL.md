# Skill: 学术搜索 (Academic Search)

> 帮学生查找目标院校、导师、实验室信息，生成套磁信草稿。

## 触发

用户说"帮我找学校" / "查导师" / "套磁" / "academic search"。

## 输入

- 学生的研究方向/兴趣
- 目标地区（默认：全球）
- 学历层次：硕士 / 博士 / 博后
- 预算限制（可选）

## 流程

1. **需求澄清**：确认方向、地区、时间线
2. **院校筛选**：根据方向匹配院校 + 导师
3. **导师画像**：每个导师的近期论文、招生情况、风格
4. **套磁信草稿**：基于导师研究 + 学生背景生成个性化草稿

## 输出格式

```markdown
## 学术搜索结果

### 匹配院校 & 导师

#### 1. {学校名} — {导师名}
- 研究方向：{...}
- 近期代表作：{2-3篇}
- 招生状态：{确认招生 / 不确定 / 已满}
- 匹配度：⭐⭐⭐⭐⭐
- 套磁信草稿：
  > Dear Prof. {Name},
  > ...
```

## 约束

- 信息必须可溯源（附链接或出处）
- 套磁信不能千篇一律，要体现学生读过导师的论文
- 明确标注信息来源的时效性（"据2025年信息"）
