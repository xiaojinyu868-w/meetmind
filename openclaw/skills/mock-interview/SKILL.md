# Skill: 模拟面试 (Mock Interview)

> 导师根据学生的申请方向，进行结构化模拟面试并给出反馈。

## 触发

用户说"我要练面试" / "模拟面试" / "mock interview"。

## 输入

- 申请方向（如：CS PhD, 设计硕士, 博后位置）
- 面试类型：`套磁面` | `正式面` | `委员会面`
- 语言：中文 / English
- 轮数：默认 3 轮

## 流程

1. **热身**：1个轻松问题，让学生进入状态
2. **核心轮**（3-5轮）：
   - 基于申请方向提问（研究动机、方法选择、反问环节）
   - 每轮后给一句简短即时反馈（"这个回答可以更具体"）
3. **总结反馈**：
   - 回答质量评分（1-5）
   - 每轮具体改进建议
   - 推荐准备方向

## 输出格式

```markdown
## 模拟面试反馈

### 面试概要
- 方向：{...}
- 类型：{...}
- 总轮数：{...}
- 综合评分：⭐⭐⭐⭐☆

### 逐轮回顾

**Round 1: {问题}**
- 你的回答：{摘要}
- 评分：4/5
- 改进建议：{...}

### 准备建议
1. {最需要准备的}
2. ...
```

## 约束

- 问题要有梯度（从易到难）
- 反馈要具体（不是"回答得好"，而是"你用了X例子很有说服力"）
- 不一次性抛出所有问题，一轮一轮来
