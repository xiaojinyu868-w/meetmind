# Skill: 论文批注 (Thesis Review)

> 导师对学生的论文/开题报告进行结构化批注，输出可操作的修改建议。

## 触发

用户上传论文 PDF/文档，或粘贴论文内容，要求批注。

## 输入

- 论文全文（文本或文件）
- 学科领域（默认从 persona 推断）
- 批注深度：`quick`（5分钟快速）| `deep`（30分钟深度）

## 流程

1. **结构检查**：摘要→引言→方法→结果→讨论，标记缺失/薄弱章节
2. **学术规范性**：引用格式、数据呈现、逻辑链条
3. **创新点评估**：核心贡献是否清晰？是否有足够的 novelty？
4. **可操作性反馈**：每个问题配一条具体改法（不是"这里不好"，而是"改成这样"）

## 输出格式

```markdown
## 论文批注 — {标题}

### 总评
- 整体完成度：⭐⭐⭐☆☆
- 最强部分：{...}
- 最需改进：{...}

### 逐节批注

#### 摘要
- 🔴 {严重问题}
- 🟡 {改进建议}
- 🟢 {做得好的}

#### 引言
...

### 修改优先级
1. {最高优先级修改}
2. ...
3. {最低优先级修改}
```

## 约束

- 批注必须有根（指回原文具体段落）
- 不改写论文，只给建议
- 语气跟 persona 走（温和/犀利）
