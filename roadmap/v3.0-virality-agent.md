# v3.0 — Agent 即分享单元

> **一句话**：场景上下文从「个人收藏」升级为「可被分享的、有人格的容器」。每一段共享的上下文 = 一个可对话的 Agent。增长单元不是用户，是 Agent 在班级里被「传」了几次。

这份文件是当前所有产品决策的北极星。和它冲突的旧文档（v2.0 学习可见性、UPGRADE_PLAN 中关于"个人化薄弱点优先"的部分）以**本文件为准**。底座工艺（M1 可观测、M2 ASR 飞书级、M5 热词、M9 agent-native、M10 mode-driven prompts）继续生效，本文件只重定义"在底座上做什么样的产品"。

---

## 1. 我们之前为什么走偏

旧战略默认 MeetMind 是个**人学习产品**——录课 / 收集 / 收纳 / 个人 Echo。增长靠"用户觉得好用 → 自己拉同学"。这条路在校园场景里增长太慢，原因有三：

1. **产物私有**：闪卡 / 学习报告 / 薄弱点都是个人的，**没有天然分享动机**
2. **分享形态单薄**：仅 EchoShareCard 一张图，对方读完就走，**不会接话**
3. **裂变颗粒度错了**：单元是"用户"，但学生的真实组织单位是"班级 / 小组 / 组会"

GET 笔记 / 飞书妙记做不到的事：分享一份文档，对方读完就走；**分享一个 Agent，对方一问就产生新数据，新数据又能被再次分享**——这才叫 viral loop。

## 2. 新的产品同构性

| 维度 | 旧 | 新（v3.0）|
|---|---|---|
| 上下文所有权 | 个人私有，偶尔分享一张图 | **公共财产，分享是默认动作** |
| 增长单元 | 一个用户 | **一个班级里被传的一个 Agent** |
| 裂变载体 | EchoShareCard（图）| **一个能对话的 Agent** |
| 应用矩阵分组 | 单一矩阵 | **「带回去用」（个人层）/「分享出去」（场景层）两组** |
| 多课组织 | 系统聚类 | **用户主动框定 collection，后台静默学聚类** |
| Agent 数量 | 一个同学 | **同一个同学，多个上下文束。"Agent 心智"是 UI 比喻，不是后端进程** |

## 3. 场景上下文 vs 个人上下文（沿用 memory #19894860）

|  | 场景上下文 | 个人上下文 |
|---|---|---|
| 内容 | 你接触过的学习内容（听过的课、做过的题、看过的资料）| 你的学习特质、掌握水平、薄弱点、学习节奏 |
| 特点 | 同班可共享 | 因人而异 |
| 在 v3.0 里的角色 | **裂变载体**（Agent 是它的具象形态）| **付费壁垒**（永远不主动分享）|
| 应用矩阵 | 思维导图 / 速查表 / 测验 / 信息图 / 播客 | 闪卡 / 薄弱点 / 学习报告 / 同学版课堂笔记 |

**铁律**：个人层数据**永远不进 SharedAgent.snapshotJson**，除非用户在分享时勾选明确同意。这不是技术限制，是产品承诺。

## 4. 应用矩阵分层（拍板版）

| 应用 | 层级 | 单课 | 单元 | 公开分享 | 备注 |
|---|---|---|---|---|---|
| 思维导图 | 场景层 | ✅ | 跨课主干合并（缺口）| ✅ | 班级群里炫耀感最强 |
| 速查表 | 场景层 | ✅ | 单元速查（缺口）| ✅ | 考前最后一刻最强裂变 |
| 测验 | 场景层 | ✅ | 单元抽题（缺口）| 🔥 最强 | 分享出去要答才看到分 |
| 信息图 | 场景层 | ✅ | — | ✅ | 适合朋友圈 / 小红书 |
| 播客 | 场景层 | ✅ | 系列播客（缺口）| ✅ | 通勤时段裂变 |
| 学习报告 | 个人层 | ✅ | 阶段性（缺口）| 🔒 默认不分享 | 答题数据私有 |
| 闪卡 | 横跨 | ✅ | 跨课闪卡（缺口）| 🔒 默认私有；🔥 班级共错卡可分享 | 个人层 / 场景层双向出口 |
| 薄弱点雷达 | 个人层 | 缺口 | 跨课薄弱模式（缺口）| 🔒 永不分享 | 真正壁垒 |
| 同学版课堂笔记 | 中间态 | 缺口 | — | 用户决定 | 默认私有，可显式分享 |

UI 上**两组分开陈列**，场景层的应用卡右上角默认带「分享」icon，个人层的没有。这是肌肉记忆层面的引导。

## 5. 「分享一个 Agent」的形态约束

### 5.1 SnapshotShare（不是 LiveShare）

每次分享 = **share-time 刻一份快照**。原作者后续修改自己的笔记 / 转录 / 对话历史，**不影响**已经发出去的分享。原因：

- 隐私：原作者的后续私人对话不应回流到分享出去的副本
- 稳定：班级群里发的链接，下周打开还能看到当时的样子
- Taste：对齐「你随手种下的，会安静地长成」——分享是种子，不是订阅源
- 工程：snapshot 是不可变值，缓存 / CDN / 反爬都简单

### 5.2 分享载荷必含字段（最小集）

```ts
SharedAgentSnapshot {
  title: string                  // 课程名 / 讨论主题
  artifactKind: 'cheatsheet' | 'mindmap' | 'quiz' | 'flashcards' | 'infographic' | 'audio-overview' | 'notes' | 'chat-only'
  artifact?: AppExecutionResult   // 选定的具体产物（场景层）
  transcriptDigest: TranscriptDigest // 转录摘要：原文不全量带（隐私），带可索引的段落 + 时间戳
  subject?: string
  sharerNickname: string          // 不带真实姓名，避免社工
  sharedAt: string                // ISO timestamp
  conversationContext: string     // 给"分享态 Agent"的 system prompt 注入材料
}
```

**故意不包含**：原作者的对话历史、个人画像、任何个人层应用产物（闪卡 / 薄弱点 / 学习报告）。

### 5.3 「分享态 Agent」对话边界

`/api/tutor/agent` 新增 `mode: 'shared'`：

- 上下文只来自 `SharedAgentSnapshot.conversationContext` + `transcriptDigest`
- **不读取**原作者 / 访问者的 workspace 历史、笔记、画像
- 访问者的对话写到**他自己的** conversation（如登录），或临时 cache（匿名）
- system prompt 自我介绍："我是 Alice 听完《第三章 决策树》后留下的同学，能基于那节课的内容回答你"

### 5.4 增长动作（按转化漏斗）

```
Alice 录完一节课
  → Octo Buddy 抱着今天的"结晶"出现，让她选一个产物
  → 生成一个 SharedAgent + 短链 + ShareAgentCard 长图
  → Alice 发到班级群

Bob 在群里点开
  → 落地页 = Octo Buddy 在等他 + 产物预览 + 一句开场白
    "Alice 听完了《第三章 决策树》，给你留了一张速查表 + 想问你三个问题"
  → 匿名可读 / 可点几下，但要对话需要登录
  → 登录后 Bob 进入分享态对话，能问任何关于"那节课"的问题
  → 看完两个明确动作可见：
    a. 「领取到我的工作台」 = 在 Bob 的 workspace 创建一个 capture，绑定到 source share
    b. 「也分享给别人」 = 复用 Alice 的分享链接，或基于自己的对话再生成一个 SharedAgent

Bob 领取后
  → Bob 的工作台多了一节"来自 Alice 的课"
  → Bob 自己继续问、做闪卡 / 测验，这些都是 Bob 的私人数据
  → Bob 接下来录自己的课，又能分享给其他人
```

裂变系数 K = 平均每个被分享 Agent 触达的新登录用户数。**k > 1 是 v3.0 唯一的成功条件**。

## 7. 文案 & Taste 边界

- 角色名仍然是「**同学**」
- 增量首选词：**结晶**（分享出去的产物）/ **递给同学**（分享动作）/ **领取**（claim）
- 禁用：「邀请」「分享卡 V2」「Agent 矩阵」「裂变」（开发者黑话）
- 仪式时刻：录课结束 Octo Buddy 抱结晶出现，使用"录音停止 + Echo 卡片完成"那条仪式（白名单第 4 条）
- 安静原则：没有"X 个同学正在看你的分享"这类大字提示，只在落地页右下角极淡地显示一行"已被打开 N 次"

## 8. 技术边界

- **不引入多 Agent / Agent-of-Agents 架构**（违反 Bitter Lesson）
- **不引入活分享**（订阅源、协作编辑都不做）
- **不引入新 LLM provider**（继续用 DeepSeek / DashScope / OpenAI-compat）
- **不动 ASR / Tutor 主链路** —— 分享态只是 mode，路由依旧 `/api/tutor/agent`
- **数据库继续 SQLite**（M11 范围内不迁 Postgres）

## 9. 验收标准

- [ ] Alice 在课堂界面 3 步内能生成 SharedAgent + 长图
- [ ] Bob 用任何浏览器无登录都能打开链接看预览
- [ ] Bob 登录后能与"分享态同学"对话，回答只基于 snapshot
- [ ] Bob 能一键领取到自己 workspace
- [ ] 分享后修改 Alice 的源笔记不影响 Bob 看到的副本
- [ ] `make check` / `make eval-tutor` 全绿
- [ ] 班级 5 人样本测试：k > 1
