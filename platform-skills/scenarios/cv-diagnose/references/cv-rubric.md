## <a id="phd-us-cs"></a>PhD · 美国 CS

### 评分维度 + 加减分点

**学术背景 / 5.0**
- 起点：本科学校排名（清北复交 / 国内 top 15 / 其它 985 / 211 / 其它）
- GPA 要求：前 20 program 基本 3.8+ / 前 50 3.5+ / 其它 3.3+
- 加分：数学/理论课有 A 成绩（特别是离散数学、概率、矩阵论、算法设计）
- 减分：大一大二失败课没 retake

**科研经历 / 5.0**
- 核心：至少 1 段真实的长期研究经历（≥1 年），有清晰的 role（独立项目 / 核心贡献者 / 辅助）
- 硬指标：ACL / EMNLP / NAACL / CVPR / ICCV / NeurIPS / ICML / ICLR / SIGGRAPH / OSDI /
  SOSP / PLDI 等 top venue 的 paper（哪怕是 workshop 一作都算）
- 次级：国内好会议一作（CCF A 类）/ arxiv preprint + 有正式 reviewer
- 加分：参与过海外 top lab 的 visiting research
- 减分：只有"参与过某某项目"但说不清自己做了什么

**技术能力 / 5.0**
- 栈：目标方向的主流技术（NLP → PyTorch / HuggingFace / FSDP；Systems → Rust/C++ / eBPF / Linux
  kernel；ML Sys → CUDA / Triton / Megatron）
- 加分：有 production-scale 的 open source 贡献（merged PR to mainstream repo）/ Kaggle medal /
  ACM-ICPC region medal
- 减分：只有课堂项目，没 end-to-end 做过一个可运行的系统

**故事线 / 5.0**
- 核心：这份 CV 能让 admission committee 看完知道"这个学生想做 X，已经做过 Y，准备来做 Z"
- 减分：experience 段列了一堆看起来无关的实习/项目，拼不出方向
- 加分：推荐信签名人和 target faculty 在同一个 research community（哪怕不是直接朋友）

### 硬伤常见清单（按频次）

1. **没有 workshop 以上 paper** — 美国 top-20 PhD 几乎必须；补救：把当前 in-progress 的项目在
   2-3 个月内推到一个合适的 workshop (如 NeurIPS/ICLR/ACL 的 workshop track)
2. **推荐信签名人 research area 跟 target 不对齐** — 补救：主动联系一位 target community 里的老师做
   3-6 个月 RA，换推荐信
3. **GPA 3.4-3.6 且没有 high-impact 论文** — 补救：强化科研维度补偿，或从 MS → PhD 路径切
4. **experience 列表没有主线** — 补救：重写 cover story，砍掉 2-3 段最弱的实习，集中讲 2 段核心
5. **英语 testing 差**（TOEFL 99 以下 / GRE V145 以下）— 补救：重考

## <a id="phd-hk-sg-cs"></a>PhD · 港/新 CS

### 关键差异

- 比美国 top-20 更看重：**具体导师的匹配度**（因为港/新 supervisor 决策权比美国大）
- GPA 要求可以低一档但**套磁成功率权重上升**
- 科研 paper 要求略低，但**RA 经历要求更长**（≥1 年 + 有 named author）

### 额外加分

- 有直接和目标导师合作过 / 有 meeting 记录
- 有 MPhil → PhD 的过渡规划（港大/中文 MPhil 路径）
- 英文表达好（面试强势）

### 额外减分

- CV 里缺少"找到了具体目标导师的匹配点"这条线

## <a id="ms-us-cs"></a>Master · 美国 MS CS

**学术背景 / 5.0**：GPA 优先于学校（3.5+ 能走大部分 top 50）
**技术能力 / 5.0**：open source / 工业实习经历 > paper
**故事线 / 5.0**：要明确走就业向 or 读博向（两者申请策略完全不同）

### 硬伤常见清单

1. 只投 top-10 CS，不投 top-30 保底 — 高风险
2. 没有美国/欧洲/新加坡公司实习 — 对工业向 MS 扣分严重
3. 申请文书全是科研故事但 target 是就业向 program

## <a id="mfin"></a>Master · 金融工程 / MFin / MFE

**核心维度**：数学 / 编程 / 金融直觉 / 实习（BB / hedge fund / quant shop 有权重差）

- 数学：随机过程、测度论、线性代数、优化（每一门 A/A-）
- 编程：Python + C++（ideally 俩都熟）
- 实习：Top-tier（BB 前台 / 大型 hedge / top quant shop）> 国内大厂金工 > 普通券商

### 硬伤常见清单

1. 只有国内券商实习 — 顶级项目（Princeton MFIN / CMU MSCF / Columbia MFE）很难进
2. 没有 quant competition 参与过（Kaggle / Jane Street / IMC）
3. GRE Quant 未满 170

## <a id="red-lines"></a>通用红线（出现 → CTA 之前必须谈）

不是 rubric 项，但一旦在 CV 里看到就要在 showDraft 里**明确警示**，CTA 的 reason 里必须提到。

1. **诚信问题**：虚假实习 / 虚假 GPA / 虚假 paper 作者位次 —— 发现立即强警告，拒绝继续生成 CTA
2. **学术处分 / 重大挂科** —— 不是硬伤，但必须在第 3 条"硬伤"位显式提出，给"诚实 disclose 策略"
3. **GAP year 1+ 且无说明** —— 在 story line 里打 redflag
4. **背景 vs target 方向不一致（比如本科金融 → 目标 AI PhD）** —— 不是红线但必须处理，给"转行叙事"
   的最短路径
