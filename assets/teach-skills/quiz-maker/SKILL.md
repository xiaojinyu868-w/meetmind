# 出题与判分（quiz-maker）

> 自研首发 skill（2026-09，P2）。治理见 `../DOMAIN.md`：判分准确率与讲评质量进 eval 门禁。

本课堂没有预制 quiz 页面——出题、作答、判分全部发生在活对话与白板上。本 skill 规定这个闭环的形态与判分纪律。

## 闭环形态

1. **出题上板**：题干用 wb_draw_text（公式用 wb_draw_latex），elementId 用 `quiz_q1`、`quiz_q2` 稳定编号。选项/填空要求一并写清。
2. **暂停等答**：发 discussion 暂停，口播一句话交代"答完发消息给我"。**答案与解析此刻不上板、不剧透。**
3. **学生作答**：学生以下一条消息作答。没答完就催答要轻，一次就够。
4. **判分**：按下面的判分纪律逐题判定。
5. **讲评落笔**：判定结果与讲评用 wb_draw_text 落板（引用 `quiz_q1` 等 elementId 让对错有锚点），口播讲清"对在哪/错在哪/为什么"。需要时用 spotlight 指到对应题目。

## 出题纪律

- 一次出 1–3 题，服务当前课题的诊断目标——每道题都要能回答"它在诊断哪个理解点"。
- 客观题（选择/判断/填空/计算）优先：判分要明确、可复核。主观简答题可以出，但判分标准要在出题时心里写明。
- 干扰项来自真实迷思概念，不是凑数。
- 难度贴合学生在本课已显露的起点；不出需要尚未讲过内容的题。

## 判分纪律（红线）

- **客观题给明确答案**：判分依据是题目本身的确定答案，不含糊其辞。判对/判错/部分对，三态说清。
- **常见错因**：判错时必须给出最可能的错因（哪个概念断点、哪步运算跳步），讲评针对错因而不只是给正确答案。
- **以学生消息原文为准**：只判学生实际说出的答案；表述含糊时先口头确认其意思，不替学生脑补成对或错。
- **不自相矛盾**：讲评内容与板上已有内容冲突时，先修正自己，再继续。
- 判分结果不上来就念内部评分细则；学生听到的是"对/错 + 为什么"。
