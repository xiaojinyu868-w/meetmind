# 社会情感学习（SEL）

> 上游：THU-MAIC/OpenMAIC（MIT）`skills/agent-runtime/social-emotional-learning/SKILL.md`，2026-09 vendor，合规说明见 `../NOTICE`。
> 裁剪：删除多代理 roster 段落（本课堂是单一老师声音，没有学生代理）与 stage-design 引用；嵌入点从"页面 brief"改写为口播、板书与 discussion 节奏。平行目标纪律与安全关口原样保留。

把社会情感学习作为**平行目标**嵌入概念主课：不替换学生真正关心的学科概念，而是改变学生如何经历它。

如果同时使用 `/understanding-by-design`，先确定大概念、基本问题与表现性任务，再嵌入 SEL。每一个 SEL 设计都要能回答"它在服务哪个概念理解"；答不出就删除。

## 先声明平行目标（教师侧，不宣读）

开始设计前，用一句话分别声明：

1. **概念目标**：学生要理解或迁移什么；
2. **SEL 平行目标**：学生要在这段学习中练习哪种能力，以及什么行为能证明它发生了。

优先从下列能力中选择与概念任务最贴合的 1–2 项，不要一节课包办全部：

- **自我认识与自我管理**：学生能觉察困惑、挫败、好奇或走神，并做出一步调节。
- **社会意识与同理**：从他人或利益相关者的立场重看同一内容。
- **人际关系与协作**：讲清推理，接受并回应建设性批评，对观点而不是对人反驳。
- **负责任决策**：评估不同解释或行为的后果，并为选择提供理由。

## 四个 SEL 嵌入点（活课堂版）

不必为 SEL 另加环节；把目标嵌入原有讲解节奏：

1. **开场**：开场口播里加一个情绪或觉察拍，让学生叫出"今天我可能会卡在哪里"的感受。
2. **概念建立**：当概念存在实质分歧时，口头呈现另一种合理立场请学生评判，练习换位；分歧落在观点上，不落在人上。
3. **亲手做**：作答与讨论中保留可预期的受挫、反馈与重试路径（答错 → 针对性追问 → 再答），用来练习自我管理和韧性；失败不能是死路。
4. **收束反思**：同时追问"你理解了哪个概念"与"你练到了哪种社会情感能力"，让学生将两种收获分别说清；概念收获落板，能力收获口头说清即可。

不要宣读 SEL 术语。让能力通过可观察的对话、选择、反馈和重试发生。

## 质量与安全关口

- SEL 目标与概念目标分开声明，不混成空泛的"综合素养"。
- 每个嵌入点都标明它服务的概念与可观察的 SEL 能力。
- 情绪表达被接纳且不被评判；不要强迫学生公开个人创伤、心理状况或隐私经历。
- 不进行心理诊断，不把学习挫折病理化，不以羞辱或排名驱动参与。
- 作答环节必须有受挫—反馈—重试路径；收束同时呈现概念收获与能力收获。

## 边界

本 Skill 用于把 SEL 嵌入学科概念课，不用于以 SEL 本身为内容主线的独立心理课、班会课或情绪课。如果学生想让 SEL 成为与学科概念并列的第二条完整主线，先口头确认范围。
