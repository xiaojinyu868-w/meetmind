# K-12 核心素养课堂设计

> 上游：THU-MAIC/OpenMAIC（MIT）`skills/agent-runtime/k12-core-literacy-planning/SKILL.md`，2026-09 vendor，合规说明见 `../NOTICE`。`references/` 目录（课标素养维度与分学科指南）原样保留，用 read 工具按需加载。
> 裁剪：删除 stage-design/pro-editing/create_stage/generate_scene/generate_tts 等课件持久化工具链与 ask_user 表单（本课堂无预编排页面，确认走自然口播）；页面类型规划改写为活课堂环节（口播/板书/discussion，出题走 `/quiz-maker`）。真实情境不变式、学习契约、分学段纪律与完成检查原样保留。

围绕中国课程标准的核心素养模型设计一节**实时一对一课**。交付物是这节课本身：讲解、板书、学生的活动、评估证据都在对话与板书中发生。

不变式：

**真实情境 → 表现性任务 → 学习活动 → 可观察证据 → 迁移**

## 规划前先落地学科与学段

开始设计前确定学科与学段，然后用 read 工具加载（必须，不能凭记忆写素养维度名）：

1. [`references/core-literacy.md`](references/core-literacy.md)，必载；
2. 一份匹配的学科指南：
   - 语文/外语：[`references/subjects/languages.md`](references/subjects/languages.md)
   - 数学：[`references/subjects/mathematics.md`](references/subjects/mathematics.md)
   - 科学/物理/化学/生物：[`references/subjects/science.md`](references/subjects/science.md)
   - 历史/地理/道法/政治：[`references/subjects/humanities.md`](references/subjects/humanities.md)
   - 信息科技/艺术/体育健康/劳动：`core-literacy.md` 中对应章节

如果年级或课题确实未知，至多口头问两个关键问题（一轮问完）。其余默认：45 分钟、一般课程质量期望、UDL 支持。请求或材料里已有的信息绝不再问。

如果老师点名教材版本、课标条款或提供了材料，对齐它；否则用通用课程表述，并说明本课未对齐特定教材版本。绝不编造标准编号、引文或材料事实。

## 立下学习契约

一节课只选 **一到两个**主素养维度。开讲前以此形式声明契约（教师侧）：

> 学生将 **做 X**，使 **素养维度 Y** 通过 **证据 Z** 变得可观察。

"理解""掌握""培养思维"这类弱目标不是契约。用可见动词：标注、建模、比较、论证、检验、修正、设计、决策、创造、展示。

真实情境必须贯穿整节课：

- 它制造开场问题；
- 学生在中心任务里使用它；
- 评估带着新案例或变化条件回到它。

开场后就丢掉的故事是装饰，不是情境。贴了个人名的普通练习题不是真实问题。

## 围绕学生的功课设计环节

45 分钟课默认 6–10 个环节，但不把环节数当硬上限。每个环节明确：学生的动作、收集到的证据、与相邻环节的衔接。

一个有用的默认弧线：

1. 真实情境、未决问题与最终任务（口播 + wb_draw_text 落板）；
2. 观察、阅读、搜集证据（学生口头报告发现，你落笔记录）；
3. 比较、分类、建模、细读或推理（discussion 追问 + 板书显形）；
4. 诊断最可能的迷思概念并要求给出理由（`/quiz-maker` 或口头辨析）；
5. 产出主要解释、模型、决策、文本或设计（学生产出，你板演与点评）；
6. 成功标准、支架、示范片段（板书）；
7. 迁移到同一情境的新版本（新案例作答）；
8. 可选收束：巩固学生建立的方法，点名仍开放的问题。

板书标题写学生将发现或做出什么：「拖动倾角，看射程怎么变」「两份史料为什么说得不一样」「给校园开放日改写导览词」。不用「概念介绍」「知识讲解」「案例分析」「课堂总结」。

## 通用底线

- 学生做认知功。老师提供现象、材料、问题、模型与支架，不先宣布结论。
- 主任务本身产出评估证据。出口任务用同推理/产出结构的新案例。
- 小学重具体操作、体验与短语言；初中重概念、证据与显式推理；高中重体系、模型、多源材料与有理据的价值判断。
- 至少包含一个视觉或结构支架（板书图示/对照表）、一个语言表达支架（句式/词汇支架）和一个给学有余力学生的拓展。
- 原创案例、问题与活动。教材与上传材料决定范围与事实，不是照抄给学生的文案。

## 完成检查

下课前（教师侧）逐项确认：

- 学科与学段使用了正确的课标维度措辞；
- 一到两个素养维度以学生活动与可观察证据出现；
- 真实情境从开场经任务到迁移全程存活；
- 学生至少获取、加工或比较过一次证据；
- 学生至少产出过一个解释、模型、文本、设计、决策或其他可检视的成果；
- 中心迷思概念被某个活动或题目处理过；
- 评估与学习任务同构且包含迁移；
- 没有编造课标引文、教材版本、材料事实或外部查证结果。

收束用一两句话：点名主素养维度，和让它们变得可见的那个表现性任务。不复述整节课流程。
